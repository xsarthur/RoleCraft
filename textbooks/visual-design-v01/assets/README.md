# v0.1 教学输入与视觉示意

这些文件是随教材交付的**虚构教学夹具**，不是客户素材、平台规则或真实商品照片。它们让第 2、3、6、7、12 章可以在同一输入上复现判断和修订。

| 文件 | 用途 | 状态 |
| --- | --- | --- |
| `product-pack-v01.svg` | 澄湾产品的虚构矢量占位资产 | 可编辑教学输入；不能商用 |
| `brand-swatch-v01.svg` | 临时色卡和版式锚点 | 教学假设；不等于正式品牌规范 |
| `channel-spec-v01.md` | 1:1、4:5、详情页和 16:9 的教学尺寸/安全区假设 | 教学假设；不是平台规定 |
| `claim-sheet-v01.md` | 已知、待确认和禁止自行决定的文字 | 教学输入；需业务/法务确认才可上线 |
| `feedback-card-v01.md` | 固定角色、截止时间和冲突反馈 | 教学输入；开放练习不作就业判定 |
| `case-board-v01.svg` | 原稿、层级方案、错误 AI 输出、人工修订和 4:5 安全区布局示意（E 面板明确标注非按比例） | 视觉教学示意；需设计师和 QA 复核渲染 |

SVG 中的文字、瓶身、色块和标记都为教学绘制，不暗示真实商品特性。`case-board-v01.svg` 的“错误 AI 输出”是人为编排的反例，不是某个供应商的实测结果。
