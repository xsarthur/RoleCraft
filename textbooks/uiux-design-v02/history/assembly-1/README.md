# UI/UX产品设计 从基础到高级实践

从[完整合订本](uiux-design-textbook.md)开始阅读，也可从下面的章节入口继续。

本书以澄明售后工作台为统一教学案例，循序训练问题发现、研究判断、界面与状态、系统治理、AI体验、实验和跨团队交付。初学者先做第01章诊断；有经验者可按先修补学。每章保留完整示范、失败分析和分层练习，参考解析用于理解取舍，不替学习者完成真实作品。

## 阅读路线

| 阶段 | 章节 | 形成的判断 |
| --- | --- | --- |
| 问题与证据 | 01—04 | 分清用户目标、研究观察、推断与决定 |
| 任务与界面 | 05—10 | 组织对象、流程、状态、视觉和跨端语义 |
| 可复用系统 | 11—12 | 建立组件合同，处理版本、迁移与治理 |
| AI与复杂服务 | 13—18 | 核查候选，处理控制、权限、并发与跨系统交接 |
| 评估与交付 | 19—24 | 复核效果、作资源取舍、交接并迁移未知任务 |

## 使用图稿、练习与来源

[来源与工件索引](source-index.md)列出逐章源文件、8幅静态图稿、研究与治理工件以及第20章的合成数据和复算脚本。所有章节源文件均保留，便于单章阅读与版本核对。

本版人物、研究、业务规则、金额与实验结果均为教学构造，SVG不是可交互应用。第20章程序只复算合成数据；真实模型、退款、用户研究、辅助技术、生产效果与就业能力不能由此推出。

独立复核进度与限定范围见[项目协调记录](../../team/uiux-v02-pm.md)；[组装清单](assembly-manifest.json)仅记录文件版本与链接转换，不替代专业审校或QA。
