# Agent 工程教材 v13 优化版阅读入口

这是 **Agent 工程教材 v13 的隔离阅读预览**，覆盖完整 30 个单元。它用于查看本轮教材编辑优化后的阅读体验：开篇和正文中段穿插少量有语义的视觉卡，长代码按跨端折叠约定呈现，并在图示、代码和外部契约处保留验证状态。

## 先说明版本身份

- **版本**：`textbook-v13`，优化试读版。
- **范围**：30/30 个正文单元，来源和顺序以 [assembly-manifest.json](assembly-manifest.json) 为准。
- **基线**：`textbook-v12`；v12 原文、历史审校和历史 QA 保持独立。
- **入口性质**：隔离预览，不自动替换 v12 工作台内容，也不代表职业能力认证、真人专家审核或真实学习效果。
- **图示性质**：图是帮助读者理解机制、边界、状态和证据关系的教材资产；若图片不能显示，每章保留邻近文字说明或降级描述。

## 建议阅读顺序

先读第 1 单元了解 Agent 工程全景，再按清单顺序推进。顺序先建立输入诊断、问题证据和任务验收，再进入信任边界、模型与工具、控制循环、检索编排、评估交付，最后用作品证据收口。每章的“练习/复盘卡”可作为停点，不必一次读完全部内容。

## 阅读时如何看图和代码

- 图示采用少量有语义的颜色区分阶段、状态、权限和证据类型；颜色不是唯一含义，节点文字和形状仍承担信息。
- 图通常出现在开篇总览、机制转折、失败分支或练习交接处。正文紧邻图示给出阅读任务和文字替代，避免把图当装饰。
- 按跨端合同，**11 行及以上代码默认折叠，10 行及以下默认展开**。折叠摘要应说明代码用途、语言、行数和验证状态；关键输入、输出、错误分支与结论不能只藏在折叠内容里。
- 折叠是产品、设计、开发、编辑和测试共同承担的功能约定。当前目录记录了正文中的标记；正式工作台是否展示这些交互，以产品和客户端实现及独立 QA 结果为准。
