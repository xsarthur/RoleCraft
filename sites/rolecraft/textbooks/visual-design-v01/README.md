## 版本边界

- 本稿讲“AI视觉内容设计”：设计师先理解 brief、受众、卖点、品牌和渠道，再用 AI 做受控的方案探索、变体或局部处理，并由设计师完成判断、修订、交付和说明。
- 本稿不讲 AIGC 内容生产工作流、模型训练、ComfyUI/节点编排、批量提示词系统、API 接入或内容账号运营。那些是另一条 AIGC 生产路线。
- 练习中的品牌、商品、卖点和数据均为教学虚构或明确标注的假设。真实商用前必须由业务、法务或品牌责任人确认。
- 公开岗位和面试整理只能说明样本中的要求与题型，不能推出全国岗位数量、录用概率或职业认证。
