# AI 时代 UI/UX 设计入门 v0.1

本目录是一份面向 UI/UX 设计入行者的独立教材初稿。它把用户问题、信息架构、流程、界面、设计系统、AI 交互、研究、工程协作与求职作品放在同一条证据链上。读者学完应能解释一个设计选择如何改善任务完成，而不只是展示一套漂亮界面。

## 案例和层次

全书贯穿虚构项目“灯塔学习工作台”：帮助刚入行的学习者从自然语言问题找到可信课程内容，并在 AI 推荐不确定时继续阅读、澄清或回到原文。案例输入、数据和结果都是教学假设，不代表现有职造应用已采用，也不构成真实用户研究或上线成绩。

读者只需具备文件管理、基础浏览器操作和阅读简单表格的能力。第4章以后会用 Figma、Sketch 或代码中立的术语描述；工具按钮会变化，状态、约束和交接契约不会随按钮变化。可选补学包括 HTML/CSS、浏览器开发者工具、SQL 基础和无障碍规范阅读。

每章按“结论与条件 → 机制 → 交付实现 → 取舍与失败 → 练习”推进。练习的参考分析用于说明推理边界，不是标准答案。文中的界面、AI 响应、指标和用户反馈均未在真实产品中运行，除非另有明确执行记录。

## 与课程架构规格的关系

课程架构规格 [`team/uiux-textbook-course-architecture.md`](../../team/uiux-textbook-course-architecture.md) 定义了 26 个单元、能力矩阵和八阶段实作。本目录的 v0.1 正文是 **12 章概要版**：每章合并若干单元，用一个教学案例讲通主机制，尚未逐单元写完 26 个独立深读/实作文件，也未完成规格要求的全部离线夹具、题目冻结和未知任务复验。26 单元映射、缺口和后续拆分由作者交接记录，不能把本稿 12 章目录解释为 26 单元已交付。

## 证据边界

- 本稿是教材作者交付，尚未通过独立内容审校、测试工程师验收、真人设计专家审核或真实学习者试读。
- 示例没有真实用户个人数据、模型调用、生产发布、平台审核或商业转化结果；不要把案例产物当成就业或职业认证。
- 来源文件把公开岗位/题型与作者教学建议分开。来源地区、岗位层级和页面状态有记录，不能由样本推出市场频率或录用概率。
- WCAG、平台组件库和 AI 供应商 API 会更新；正文只引用可核对的原则，项目实施前仍需按目标版本复查官方资料。
