# M105｜余弦相似度、点积和欧氏距离如何计算？向量归一化会怎样改变它们的排序关系，零向量和维度不符怎样处理？

答案版本：interview-answers-v1.0.1。完整参考解析；示例及测试计划未由本稿执行。

对于同维实向量x、y，点积为Σxᵢyᵢ；范数||x||=√Σxᵢ²；余弦为dot(x,y)/(||x||||y||)；欧氏距离为√Σ(xᵢ−yᵢ)²。点积/余弦越大通常排得越前，欧氏距离越小越近。这里“相似”只指选定向量空间的度量，不能直接等同文本事实正确。

关键推导来自展开平方：||x−y||²=||x||²+||y||²−2dot(x,y)。若查询和文档都归一化为单位向量，则cos(x,y)=dot(x,y)，距离平方=2−2cos。减二倍和平方根都保持相应反向排序，所以最大余弦、最大点积和最小L2得到相同排序（数值误差与并列的确定性规则另计）。对一个固定非零查询，候选文档等范数也有相同排序关系；仅把查询归一化而保留长短不同文档，则不能保证。

反例取q=(1,0)，a=(2,0.2)，b=(1,0)。点积分别2和1，选a；余弦a≈0.995、b=1，选b；L2a≈1.020、b=0，也选b。a变长增加点积，却没有变得方向更准确。若全部归一化，q=b，a约(0.995,0.0995)，三种排序都选b。归一化改变的是表示/度量约定，是否应做须遵循嵌入模型训练目标，不能只为排序一致擅自改。

下面是未执行的纯标准库教学计算，拒绝空向量、维度错、零范数和非有限数。显式界定绝对值不超过1e100及维度1024是为了避免本例中间运算溢出，不是向量模型通用上限。

```python
import math

def metrics(x, y):
    x, y = tuple(x), tuple(y)
    if not 1 <= len(x) <= 1024 or len(x) != len(y):
        raise ValueError("dimension")
    for v in x + y:
        if type(v) not in (int, float) or abs(v) > 1e100 or not math.isfinite(v):
            raise ValueError("finite bounded number required")
    nx, ny = math.hypot(*x), math.hypot(*y)
    if nx == 0 or ny == 0:
        raise ValueError("zero vector has no cosine")
    dot = math.fsum(a*b for a, b in zip(x, y))
    cosine = math.fsum((a/nx)*(b/ny) for a, b in zip(x, y))
    distance = math.hypot(*(a-b for a, b in zip(x, y)))
    return dot, cosine, distance

q, a, b = (1, 0), (2, 0.2), (1, 0)
ma, mb = metrics(q, a), metrics(q, b)
assert ma[0] > mb[0] and ma[1] < mb[1] and ma[2] > mb[2]
unit_a = tuple(v / math.hypot(*a) for v in a)
dot, cos, dist = metrics(q, unit_a)
assert math.isclose(dot, cos)
assert math.isclose(dist*dist, 2 - 2*dot)
for bad in [(0, 0), (float("nan"), 0), (1, 2, 3)]:
    try:
        metrics(q, bad)
    except ValueError:
        continue
    raise AssertionError("expected input rejection")
```

数学上零向量仍有点积/L2，但没有余弦；这个统一接口为防混用把它整体拒绝。业务可另定义零向量降级，不能除零后默默给最高分。实现还应固定float精度、并列排序与距离是否平方；Faiss的L2通常返回平方距离，排名等价但阈值不同。[Faiss度量文档](https://github.com/facebookresearch/faiss/wiki/MetricType-and-distances)，核查于2026-10-14。测试应包含同向、反向、正交、尺度变化和错误输入，代码运行结论待独立验证。
