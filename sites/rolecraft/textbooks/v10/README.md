## 概要与实作入口

概要先看开篇、[问题发现](p01-discovery.md)、[任务验收](02-task-acceptance.md)与 [信任边界](03-trust-boundary.md)，再预览 [方案选择](c01-selection.md)和 [动作身份](c01-control-primer.md)。概要帮助确定目标和限制，完整实现仍按先修推进。

零基础先完成 [基础预备的诊断](01-foundation.md#先做入口诊断)及对应补学；已有基础者保留相同诊断证据后可跳过补学。各阶段产物与回退路径沿用 [实作方法](../../team/textbook-v09-curriculum.md)。真实MVP在问题和评价证据基础上决定，首次真实敏感读取或外部写入前先完成强制边界并取得实际授权。
