# UI/UX v0.2 八图设计交接

## 交付身份与边界

本文件仅根据同目录八张 SVG 的 `title`、`desc` 与可见文字整理交接，不构成视觉渲染、技术实现或验收报告。八图均为教学合成、静态、可编辑源：姓名、订单、政策、金额和业务证据为教学数据；没有实现点击、真实滚动、焦点管理、服务端授权、支付接口或真实用户验证。图中文字描述的保护措施是待实现契约，不能据此声称系统已具备相应能力。

主线对象为 `T-1042 / O-7819 / R-81@v4 / CNY 268.00 / P-07@v3`；图中 `¥268` 与此金额对应。林晓为仅具 `t-lotus` 基础客服权限的单租户人员，可申请，不得据图推导批准或执行权限；许然为主管。跨租户边界例使用独立演员顾宁 `XS-01`：在 `t-lotus`、`t-maple` 分别拥有基础客服授权，无审批权。双租户授权不能转移给林晓，也不代表跨租户数据可混用。

## 状态与交互交接约束

- 八图是不同教学快照。图02“尚未执行”、图03“查询后成功”及图07的变体不可当成同屏同刻状态。完整状态矩阵见 [STATE_MATRIX.md](STATE_MATRIX.md)。
- 草稿生成、消息发送、批准提交、退款执行和权威结果必须分别表达。超时只改变已知信息；效果未知时保留原请求和查询/人工接管入口，不开放重复退款。
- 批准绑定租户、对象、金额/币种、理由、政策及申请版本。图07 T03的 `R-81@v5 / CNY240` 是内容变化反例，不是主线金额修订；原批准不得沿用。图07 T02的 `P-07@v4` 同为独立来源更新例。
- 图07 T05的 `VIS-07-T05@v1` 为独立10项教学批次；与正文第06单元 `B-06@v1`、第17单元 `B-12@v1` 不同，不互借计数、状态或通过证据。
- 图06“切租户先处理当前编辑”为客户端通用规则，不给主线单租户林晓增加权限；跨租户演示仅按图07 XS-01顾宁的独立授权解释。

## 实现后的验证清单（本交付未执行）

1. 按真实DOM顺序检查键盘可达性、名称/角色/值、弹层初始焦点与关闭后返回、错误摘要到字段的定位、状态宣告及减弱动态效果；禁用状态不得只靠颜色传达。
2. 分别检查图04标注的WCAG 2.2 1.4.4文本放大与1.4.10重排；200%文本与320 CSS px等价重排不能互相替代。图示采用1280视口400%缩放作为重排检查路径提示；适用内容、例外及实际结果由实现后的独立QA依据规范确认。
3. 本设计采用44的按钮目标高度；不可直接以此认定2.5.8通过。实际命中区域、间距、适用例外及不同主题/状态对比度均须另行检查。
4. 实际点击、服务端权限/租户/版本校验、并发与迟到拦截、支付幂等/对账/恢复需工程实现及独立测试证据；不得以SVG文字作为已实现证据。
