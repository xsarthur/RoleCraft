## 启动与停止

先进入工作区根目录 `一人公司建设`，在支持 `node:sqlite` 的 Node.js（至少22.13）运行：

```sh
node scripts/start-local.mjs
```

如果已进入 `sites/rolecraft` 项目子目录，请运行 `node ../../scripts/start-local.mjs`；启动脚本实际位于工作区根目录 `scripts/`。

默认服务仅监听本机 `http://127.0.0.1:4318/#generation`，实际地址以终端输出为准；停止按 `Ctrl+C`。`ROLECRAFT_PORT` 可改变端口。账户、任务、草稿、作品与复盘持久数据默认位于项目 `.runtime/rolecraft.sqlite`（WAL），不是浏览器存储；`ROLECRAFT_DATA_DIR` 可设置独立目录。恢复同一数据目录后重新登录读取保存记录。若当前Node过旧请使用已支持SQLite的研发运行时；不必安装前端构建依赖。

直接打开 `dist/index.html` 仍可使用静态学习功能及阅读作者e03初稿。`file://` 没有同源API，新生成页明确提示服务启动，不直接请求模型；普通Python静态服务器也不能替代本地研发服务。file与HTTP来源中的旧浏览器记录可能分离，不自动导入或传送旧 `rolecraft-v1`。

## 服务端生成配置

仅通过服务端环境提供下列配置，不在网页、源码、记录或客户端localStorage填写真实密钥：

- `OPENAI_API_KEY`：研发服务的真实供应商凭据。
- `OPENAI_MODEL`：实际授权可用模型；项目不编造可用模型。
- `OPENAI_MAX_OUTPUT_TOKENS`：本次最大输出长度（服务校验256–16000）。
- `ROLECRAFT_GENERATION_BUDGET_USD`：本次试验前经实际授权确定的预算。
- `ROLECRAFT_ESTIMATED_MAX_COST_USD`：按实际模型及限制估算的单次最大费用，不得超过预算。
- `OPENAI_TIMEOUT_MS`：可选超时（默认60000）；此数值不承诺供应商已经停止处理。

缺配置／预算会阻止真实生成，不退回模拟教材。注册、阅读作者初稿、作品与复盘保存不需要供应商配置。输入预算校验不是供应商硬性费用封顶；未知调用费用与真实账单须分别核对。本轮没有执行真实供应商调用，不能把模拟结果计为真实生成证据。启动服务本身不触发生成，任务与失败后的重试由明确用户请求触发。

## 身份、任务与证据边界

账户只用于本机研发。Cookie会话与CSRF来自同源服务，私有资源以服务端身份归属；客户端不自报审核身份，也不在localStorage存密码、会话、密钥或新账户产物。退出／401会清空私有界面快照及未提交输入，旧账户异步响应有版本隔离；未提交表单仅暂存页面内存，刷新前请提交。账户导出不含密码及供应商秘密。

新画像仅 `beginner/intermediate/advanced`，由用户明确选择；不映射旧档案 `beginner/developer/practitioner`。e03先修、目标及量规保持受控输入，新稿不继承作者稿审核。作者稿及模型稿来源分别展示，测试模拟明显标注；九节正文作为转义纯文本Markdown阅读，不执行HTML或任意来源链接。受控来源只开放两份OWASP官方HTTPS链接。

页面轮询读取真实持久任务及事件，不猜百分比，不重建编辑中的表单。成功只表示草稿已保存；取消会隔离本地任务提交，外部调用结果可能未知；重试新建关联任务保留历史。刷新后从服务读取任务、草稿、作品及复盘。任务/章节固定ID与版本，提交每次修订均新建记录；引用只是自述，服务不访问作品链接或运行代码。结构与引用关联检查不证明正确，独立内容审核、示例执行、人类专业审核和学习效果均保持真实未验证状态。

独立QA已记录本轮本地HTTP15/15、模型协议模拟13/13、客户端12/12，启动路径P2修复后复验通过。真实本地HTTP/SQLite、隔离VM及模型协议模拟有各自范围，不能称原全部回归通过。完整八门槛仍未达标，真实供应商调用、完整教学及效果、行业对比、专业审核与生产证据尚缺。当前服务由后端员工在项目经理协调下启动于 `http://127.0.0.1:4318/#generation`，实际使用以终端状态为准；浏览器与视觉/键盘/读屏实测未完成。最终源hash已绑定独立审计，审计数据打包核对专项6/6通过；完整独立证据见 `team/product-audit-v04.json`、`team/qa-v04-review.md`。工程自检仅见 `team/implementation-v04-frontend.md`。外部源码同步和发布没有执行。

## 保存与故障边界

沿用 localStorage 键 `rolecraft-v1`，保留已有档案、概念题、自查、备注和最近章节，新增学习／员工复盘及独立产品复盘记录和草稿。记录只在当前浏览器及当前来源内保存，HTTP 与 file:// 的存储可能各自隔离，不保证不同浏览器的本地文件存储一致。

保存失败时，已输入内容和记录仍在当前页面内存；页面持续提示失败，可导出学习计划或全部复盘。刷新／关闭前应先导出，内存不能抵抗页面关闭。未提交复盘可以保留草稿离开或明确放弃。损坏 JSON 回退默认档案并提示；合法记录内的异常字段尽量分别规范化。

所有用户文字在 HTML 中转义；证据链接作为文字记录，不自动请求或执行。Markdown 导出转义用户文字中的 HTML，保留字段内容和两种状态。
