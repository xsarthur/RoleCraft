# Local MVP 0.4 frozen HTTP / generation contract

Version `local-mvp-0.4`; local development only. JSON camelCase. All private resources derive owner from server session, never caller owner IDs. Cookie `rolecraftSession`, HttpOnly, SameSite=Strict, Path=/; same-origin mutations only. API errors `{error:{code,message}}`. Body max 128 KiB. No external URL fetching.

## HTTP
- `GET /api/health` → `{productVersion,mode,generation:{configured,missing[]},releaseVersion}` (no secrets). `mode` is `public-deployment` when `PUBLIC_DEPLOYMENT=true` (the public Lighthouse process) and `local-development` otherwise. `generation.configured` stays an independent readiness check.
- `POST /api/auth/register` `{email,password}` → 201 `{user:{id,email},csrfToken}` and session cookie. Password 12–128 chars. New local accounts only; not production identity.
- `POST /api/auth/login` same → 200 same; `GET /api/auth/me` → same. `POST /api/auth/logout` → `{ok:true}`. Authenticated mutation sends `X-CSRF-Token`; Origin, if present, must equal request origin. Foreign resources return 404.
- `GET /api/curriculum` → frozen curriculum package (public approved source snippets/schema, no credentials).
- `GET /api/profile` → `{profile}` or null; `PUT /api/profile` `{startingPoint:"beginner"|"intermediate"|"advanced",goal}` → `{profile}` with server revision. Goal max 2000 chars. Starting points match frozen curriculum profileLevels.
- `POST /api/generation-jobs` `{moduleId:"e03",idempotencyKey,profileVersion?}` → 202 `{job}`. Server freezes all curriculum/source/template/schema/profile versions; client cannot supply these or approve results. Same account/key+same input returns original; different input 409. Missing configuration blocks before queuing with `config_missing`/`budget_missing`, never mock success.
- `GET /api/generation-jobs` → `{jobs[]}`; `GET /api/generation-jobs/:id` → `{job,attempts[],events[]}`. Job fields `id,moduleId,status,inputHash,createdAt,updatedAt,retryOfJobId,chapterId,error,profileSnapshot,versions`. Events `{sequence,type,data,createdAt}`.
- `POST /api/generation-jobs/:id/cancel` `{}` → `{job}`; queued/running becomes cancelled, terminal unchanged. External provider cancellation outcome may remain unknown.
- `POST /api/generation-jobs/:id/retry` `{idempotencyKey}` → 202 `{job}`; only failed/cancelled; new linked job/attempt, old jobs and chapters preserved. Config rechecked.
- `GET /api/chapters` → `{chapters[]}`; `GET /api/chapters/:id` → `{chapter}`. Immutable persisted generated draft `{id,jobId,attemptId,version,moduleId,createdAt,outputHash,result,reviewStatus:{content:"unreviewed",professional:"unreviewed",examples:"not_run"}}`.
- `POST /api/submissions` `{chapterId:null|string,moduleId:"e03",productTitle,productVersion,artifactUrl,runEvidence[],actualResult}` → 201 `{submission}`. Evidence strings are references only; URLs never fetched or executed. Partial evidence allowed, server reports `evidenceStatus:"incomplete"|"self_reported"`, never verified. `GET /api/submissions` / `GET /api/submissions/:id` return owner records. Immutable new records for revisions.
- `POST /api/reviews` `{submissionId,goal,evidence[],result,gap,cause,owner,nextAction,retestMethod,retestResult}` → 201 `{review}`. Type fixed `self_assessment`, independent/professional status fixed `unreviewed`. `GET /api/reviews` / `GET /api/reviews/:id` owner only. Review input cannot submit verdict/reviewer/type; no review-pass endpoint. `GET /api/export` → `{productVersion,exportedAt,profile,jobs,chapters,submissions,reviews}` owner only; no password/session/raw provider secrets.

## Internal generation
Import `server/generation/index.mjs`, `generateChapter(input, options)`; one actual attempt, no auto retry. `input={jobId,attemptId,leaseToken,inputHash,profileSnapshot,moduleId,competencyVersion,templateVersion,rubricVersion,sourceBundle,chapterSchema,chapterSpecification,promptVersion,generationConfig}`. Curriculum engineer owns schema/source objects. `generationConfig` comes only from server environment; model engineer owns exact configuration names and validation. `options={signal,onEvent}`. No HTTP transport/test injection exposed to users.

Success `{chapterDraft,claims,examples,provenance,usage,timings,checks}` returned, then owner service atomically commits immutable chapter + succeeded + event under active lease token. Model failures throw `{code,retryable,message,evidence}`; safe evidence persisted. Stage events `sources_validating`, `generating`, `structure_validating`, `draft_ready`; API status `queued|running|succeeded|failed|cancelled`. Attempt fields include `id,number,status,leaseToken,startedAt,endedAt,error,providerOutcomeUnknown`. Running cancellation immediately fences worker; unknown external outcome recorded.

Single local worker claims transactionally with incrementing lease token and heartbeat. Lost/expired running work becomes failed `interrupted`, `providerOutcomeUnknown:true`, awaiting explicit retry; never silently reissues a chargeable request. Queued work resumes on startup. Outputs + job + event commit in one SQLite transaction; stale workers cannot commit. SQLite transaction protects local persistence, not exactly-once remote execution. Session and job ownership, timestamp/sequence, frozen input hash and output hash remain server controlled.
