# v14 教材短答与章节入口：客户端候选

软件工程师；2026-10-12（Asia/Shanghai）。客户端增量版本 `local-workbench-0.14-dialog`。依冻结产品主合同、CL14-01/02、设计与 `app-v14-dialog-api.md`，完成候选，待独立 QA。仅网站客户端领域；没有改变教材、检索算法、服务/数据库、题库、导航范围或产品门槛。

## 当前行为

现有底部检索面板改为“问教材 / Agent 学习问答”。调用同源公共只读 `POST /api/content/dialog`，使用 `credentials:omit`，只发送当前问题、已存在起点/篇节/版本字段和可选已核 canonical 上一问答主题；不发送历史聊天文本或账户资料。实际职业分类和语义召回由检索服务负责，客户端不以关键词重新分类。

五状态分别显示教材简答、职业相关未覆盖、已过滤、需要澄清和暂不可用；空/超长独立显示输入错误。answered 展示 1–3 句原文提取短答及逐句真实引用链接、1–3 个对应小节入口。引用链接在面板内定位来源卡，不改变阅读路由；入口采用服务返回并经过当前教材核对的 canonical href。原文与来源/版本/hash 默认折叠，问题/提示/短答/引文均转义为纯文本。范围提示展示服务核定的过滤子句；短追问使用来源可解释的上一主题或当前篇节，不新增生成式解答。

每次回答复核当前 corpusVersion/hash、篇节身份、源路径/hash、真实标题、href、evidenceExcerpt，以及 JS UTF-16 quoteStart/End 对应原文连续片段。逐句 citationIds 必须存在，短句必须包含于关联真实 quote；主题必须属于当次出处。来源失配整体拒显，无旧答/旧卡冒充当前回答。非 answered 状态不得携带知识短句、引用、结果或主题。相同校验用于本会话缓存和历史问题。旧 v13 查询缓存原键保留，不作为 v14 回答导入。

新发送、重试、历史选择和清除问答主题都有新请求身份；AbortController 辅助取消，旧迟到成功/错误/finally 均不能改当前问题/等待状态。提交冻结表达及上下文，等待可收起/继续阅读，完成不展开、不滚动阅读页或抢阅读焦点；同一尚待响应的问题与上下文不重复提交。重试使用该次冻结问题与上下文，澄清结构化选项提交服务给出的完整表达。清主题中止当前等待并清当次回答，后续不传上一主题。Enter/Shift+Enter/IME 延续明确键盘约束。

面板是非模态区域，aria-expanded/controls、aria-busy、单 polite 状态提示、输入错误 aria-invalid/说明均在当前结果内。追加一列来源、44px 操作、16px textarea、dvh/安全区和长文本换行样式。保留现有路由、题库、个人标记/记录键和数据包，网站阅读仍是 v12/30 篇。
