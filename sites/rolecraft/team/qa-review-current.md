## 证据缺口

- 没有公网 HTTP 响应、线上版本回显、线上目录或推荐结果，因此生产可用性和内容检索线上可用性均未验证。
- 没有真实用户完成任务、学习迁移、作品质量或留存证据；自述、测验通过和本地浏览器记录不构成职业能力认证。
- 没有真人行业专家对教材、推荐内容、职业标准或产品差异化作出独立确认。
- 没有完整浏览器矩阵：真实移动设备/IME、读屏、暗色/高对比、200% 缩放、完整导出、所有账户/职业/历史组合。
- 没有真实模型供应商调用、预算、成本、限流、恢复和生产故障演练；本地 BGE 检索与生成服务必须分开计证。
- 既有局部 QA 绑定与当前 v15 文档未形成单一发布清单，无法仅凭历史哈希判断当前线上运行的确切版本。

## 建议的复验顺序

1. 先恢复并证明公网入口与三个 API 的真实响应，锁定发布版本和资源哈希。
2. 在隔离账户执行端到端主路径和失败路径，覆盖登录、职业切换、阅读、检索、记录、导出及服务不可用。
3. 完成响应式/键盘/读屏矩阵，重点验证问答遮挡、焦点回归、历史版本标识和证据状态。
4. 运行固定检索基准集并保存每次响应；将本地语义、规则降级、真实模型模式分开报告。
5. 进行真实学习者试点与真人专家复核，再重新评估八项产品门槛和成本运营。
