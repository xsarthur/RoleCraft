# Independent startup repair QA criteria

Frozen before author handoff. This is mechanism acceptance, not a new blind-business result. Preserve historical FAIL/partial and all first-round records.

## R01 — Authorization and preservation

Only marker-scoped AGENTS/onboarding/startup changes; app, original employees, old case and method including proposals unchanged. No event/network/config/Git write or ownership expansion.

## R02 — Local method discovery

Normal documented invocation finds exactly the explicitly authorized local repository without --method-root hint. Locator is metadata only; absent/malformed/wrong locator fails closed with no filesystem search or fallback network.

## R03 — Method identity

Continue fixed origin a848db9 HEAD, exact ten-file tree, regular Git blob and worktree byte equality. Wrong origin/revision, dirty body, missing/extra tracked file, permission denial and symlink/ancestor substitution cannot produce readable fixed-method PASS.

## R04 — Bounded full content

Provide manifest and individually requestable bounded page for every selected input. Split by character/UTF8 bytes rather than line count; a single giant line must cross pages without omission or duplication. Entire serialized page remains under documented safe maximum.

## R05 — Coverage and binding

Each page stably identifies source/version/full-source hash, page index/count, byte/character range and page hash. Reassembling all pages exactly matches original bytes, including UTF8, CRLF, no terminal newline and long single lines. Manifest-only/hash-only is not fulltext delivery.

## R06 — Drift and invalid page

Out-of-range/invalid selection or changed content/version between manifest and page must be explicit; no stale page silently substitutes. Wrong source, traversal, absolute path and unsafe locator are rejected.

## R07 — Compatibility

Preserve explicit --method-root and --include-content behavior and prior supported role/evidence semantics. Metadata-only default stays body-free; ownership unknown, understanding unverified, no automatic adoption or connection claim; exit0 only mechanical.

## R08 — Current project history

At least prior validation README and validation-receipt selected and fully readable alongside existing two archives/two closeout files. Preserve old FAIL/partial, AGENTS truncation/method0-of10 and document-first-failure history.

## R09 — Zero writes and private content

Checker performs no writes, no pyc under -B, no private fulltext saved to shared project or audit evidence. Fixtures contain synthetic text only, no init/clone, app/service/business execution, network or real DB/credential reads.

## R10 — Independent evidence and limits

Author tests and QA independent adversarial cases separately recorded, findings kept with author repair/retest. File hashes/current version bound; mechanism tests do not count as new blind business success or platform/global automatic loading.

QA-MEM-0001 and shared confirmed evidence/boundary preferences are applied: inspect real content and causal paths, construct independent counterexamples, preserve failures, return defects to author, and bind limited conclusions to current source. Ownership remains unknown; no management actions.
