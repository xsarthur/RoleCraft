# 语音面试离开后回访的产品交接

面向产品、工程和测试，2026年10月18日。当前源码支持在同一语音页暂停后继续录音；离开该页或卸载文档会清理本次回答。组卷设置可以另行保留，但不能恢复这次录音、转写或反馈。本稿是只读产品核对与下一轮条件草案，未实施功能、未执行独立验收。

## 当前可保留与会丢失的内容

| 学习者处境 | 当前行为与保留范围 | 对回访的含义 |
| --- | --- | --- |
| 仍在语音页，点击暂停 | 录音器和已用时仍在页面内存；存在继续录音路径。[S1] | 属于页内继续，不能推导刷新后可续录。真实录制与识别协同未在本轮实测。 |
| 停止录音后仍在原页 | 音频 Blob 和播放地址在内存；转写、反馈也放在同一临时对象。[S1] | 当前页可试听、校对和重分析，没有回答尝试的保存确认。 |
| 输入了转写但尚未确认分析 | 手工输入从文本框读取的主要路径是确认分析；没有转写输入自动保存处理。[S1] | 即便未离开，其他重绘是否覆盖未确认输入也需要复验，不能承诺草稿已保存。 |
| 点返回精选题、重新进入语音页、切换主导航，或浏览器后退/前进 | 调用 leave/reset，清空音频、计时、转写、反馈与来源模式；主导航/历史恢复还把语音面板改回首页。[S1] | 回来按新一轮准备录音处理，无法依原阶段继续。返回后显示哪个非语音面板，可能受独立保存的旧面板状态影响。 |
| 刷新、关闭文档或触发 pagehide | beforeunload/pagehide 调用同一清理；语音对象不写入面试 localStorage。[S1] | 不具备跨文档恢复；题号也没有随回答保存，初始对象为 Q1。beforeunload 在其他离开提示之前清理，取消离开后是否已丢失也应复验。 |
| 已得反馈，点击重新录音回答 | 仅把 retryPrompt 复制为本轮提示，随后 reset；旧音频、转写与反馈清除。[S1] | 同页可按提示重答，不能回来比较旧反馈；离开后提示也清除。 |
| 已配置或生成练习试卷 | 独立 rolecraft-interview-v03 保存面板、筛选、文章阶段、组卷草稿/预览/生成快照及 ready/in_progress 等字段。[S2] | 仅在同一浏览器同一来源且写入成功时可能恢复这些设置；不含本次单题回答。保存失败被捕获但没有面向用户的失败提示。 |

“切到后台或别的应用”与“离开语音页”要分开定义。当前所查清理入口没有把单纯隐藏标签当作保存点；不能把后台停留当成已暂停或已保存。

服务端现有 readiness 与 transcribe 路由，不能继续沿用历史记录“尚未挂 HTTP”的描述；所查路径没有回答存档/恢复接口，本地 ASR 临时文件在完成或失败后清理，不能作恢复副本。[S3] 原型中地址应恢复步骤、正式产品合同中的 answer_attempt 与 paused/reviewing 状态，都是需求或演示，不能替代当前实现。[S4]

## 下一轮最小验收条件草案

建议先把承诺限定为同一浏览器、同一来源的一道题回访；跨设备、账户同步和多试卷历史另议。以下是待产品冻结、由工程实现和测试独立验证的可观察条件，不是当前通过结论。

| 条件 | 学习者应能观察到的结果 |
| --- | --- |
| RH1 明确保存边界 | 开始前能知道本轮保留什么、何时可恢复；界面区分未保存、保存成功、保存失败和已恢复。失败时保留可用输入并给出复制/重试等可行出路，不显示已保存。 |
| RH2 录到一半离开 | 应用内离开前可取消并继续原回答，或明确结束本段后保留，或明确放弃。若承诺声音续答，回访须能播放前段并在用户主动操作后续答；恢复为已结束片段，不能自动重新打开麦克风。若本期只保存文字，须明确前段声音无法恢复；此时只可判文字续答通过，不能关闭录音续答目标。刷新/关页也须按冻结后的同一保留承诺核验。 |
| RH3 转写草稿回访 | 题号、题面/来源身份、最近编辑文字及是否确认一同恢复；未确认文字仍可编辑并再次确认。纠错结果、原始转写和确认状态不混用；没有文字时诚实显示需要重录/补写。 |
| RH4 反馈后回访 | 恢复对应回答的已生成反馈、重答提示、分析模式和来源状态；回访不自动再次分析。修改文字后，旧反馈清楚标为对应旧回答；新反馈成功前不把旧反馈当作当前文字结果。 |
| RH5 离开与异步结果隔离 | 离开后录音和识别确实停止；取消离开不得先清掉回答。旧题转写/分析迟到、返回原题或切到另一题时，不得覆盖新题、已放弃内容或已恢复记录。 |
| RH6 重答与删除 | 重答与继续同一次回答有明确区别；用户明确删除后再次回访不恢复被删材料，且不影响其他题、试卷、教材或旧学习记录。音频保留位置、期限和删除范围须在实现前冻结，不因增加恢复功能默认永久保存。 |
| RH7 当前版本独立证据 | 用隔离测试资料分别覆盖录音中、暂停、待确认转写、已得反馈四阶段；覆盖应用内离开、历史导航、刷新、关闭后重开，以及存储失败、迟到结果和删除。记录实际浏览器、操作、恢复内容和当前源码绑定；源码自查或旧 QA 不能代替这些结果。 |

对工程的两个静态风险交接：reset 未清 transcriptOriginal、correctionSuggestions、transcriptConfirmed 等残留字段，残留不等于有效恢复；转写与分析 Promise 回调未见对应 requestId 校验，迟到结果污染属于待复验风险。[S1] 最新项目记录另保留识别开关真值守卫问题 DQ-01：不能假设取消勾选已停止浏览器识别；回访也不能自动重启识别。[S5]
