# 产品经理交付：能力、教材与复盘标准

日期：2026-10-10。以下是本轮产品要求，尚非实现或验收结论。

## 培养目标

以“具备面向行业龙头企业业务场景的生产级 Agent 应用工程能力”为目标。能力由可复现的工程作品、评估结果、异常处理和交付说明验证；具体任务与评分由课程架构师定义。教材阅读、概念题、自查均不能直接证明胜任，目标不构成录用或企业认证承诺。

## 教材结构与质量

展示“岗位能力 → 阶段 → 章节 → 练习 → 项目证据”的关联与先修条件。广度由能力覆盖矩阵及缺口体现；精度要求每章有明确目标、概念边界、案例、练习、来源与版本、验证状态，示意伪代码明确标注。课程架构师给出标准和样例；原型仅展示结构与现有内容状态，不把目录完整称为教材成熟。

## 两层复盘与本轮最小功能

新增能力标准、课程结构、复盘中心入口，支持从教材与项目进入复盘。

- 项目复盘：选择电子员工交付物，记录责任岗位和版本，比较预期交付与实际证据，改进任务由项目经理分派原责任人。
- 学习复盘：选择章节、练习或作品，对照学习目标和能力标准记录结果，形成下一次练习或作品改进计划。

共同记录：目标、证据链接或文字、实际结果、差距、原因、改进动作、复验方法、复验结果；无结果时明确为“未复验”。保存产物标识、类型和版本，允许多条记录、编辑、刷新恢复及 Markdown 导出。项目记录额外包含责任岗位，改进动作可记录责任人和计划日期。

自述状态与审核状态分开：允许记录“自述待改进／已改进／待复验”，审核统一标为“未独立审核”；自述成功、测验通过或勾选清单不能变为专家通过。显示本地保存与导出提示。

## 交接与验收

课程交付能力矩阵、目录、先修与证据标准；设计交付三入口及复盘流程；工程按交接实现本地数据与导出；测试独立验证：

1. 两类复盘都能选择产物，学习复盘覆盖教材、练习、作品，项目复盘可追踪岗位。
2. 必填产物、目标、实际结果；证据不足、原因未确认及复验未完成可明确记录，不强迫编造。
3. 刷新后恢复多条记录及字段，编辑一条不覆盖其他记录，不丢失现有学习记录。
4. 导出保留全部复盘字段、产物版本与状态；保存失败有提示，仍可导出当前记录。
5. 能力与课程有可访问的关联，未验证状态可见；保存、自述和测验操作不产生审核通过。

未来阶段再接入真实模型、动态资料核对、代码验证、账户同步和专家复核。静态版不自动诊断原因、生成教材或评定企业岗位胜任。
