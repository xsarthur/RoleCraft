# v14 阅读详情：窄布局交接

设计师；2026-10-12（Asia/Shanghai）。依据冻结 `app-v14-detail-product.md`、当前 `learning-workbench.js` 的 readerPage、`learning-experience-v13.js` 的 relatedReader 和 v13 CSS，只读核对阅读壳层。本稿不修改代码、正文、先修关系或产品条件；浏览器布局与操作效果仍须独立 QA。

## 阅读层级与删减

全局五导航及课程学习页目录保持。详情页移除 `.lw-chapter-nav` 全书目录、常规 `.lw-reader-identity` 版本行和末尾 `.lw-textbook-info` 研发说明，不用 CSS 隐藏一份仍可聚焦的目录。顶部只留“← 返回课程”与本篇必要定位；从题目进入的已有“回到原题”保留。

本篇小节工具保留在正文前，名称“本篇小节”，继续折叠，内容仅本篇标题，不包含全书课程。正文仍使用原文章全文，首个教学标题及作者原有先修语句不删改。配套题、阅读工具、笔记、上一篇/下一篇保持既有顺序；本次只移走壳层说明和调整正式先修位置。

正式先修使用独立 `aside`/辅助区，标题“开始前需要”，随后“正式先修”与逐条真实课程链接；没有关系时直接显示“无正式先修”。短说明“可直接阅读，也可先补这些内容”，不设置强制解锁。名称必须完整换行，不能用序号、图标或省略号替代。内容完全取 `prerequisiteUnitIds`；不用相邻篇或推荐结果推断。

## 具体布局与断点

| 视口 | 正文及先修位置 | 尺寸安排 |
| --- | --- | --- |
| ≥1280px | 正文左、先修右，先修与正文开头对齐；右栏只装本篇先修 | 阅读组合最大 992px、居中；列间 32px；右栏 220px；正文列 680–740px，增长优先给正文，全文实际文字不额外内缩成窄列 |
| 761–1279px | 一列；“返回课程”后、正式文章和“本篇小节”前显示默认展开的全部先修 | 正文组合最大 740px，宽度不超当前 main 可用区；沿现有侧导航 240px 和内容两侧 28px，不预留右栏空白 |
| ≤760px | 一列；正式先修仍在文章开读前可见，不能折叠或改为抽屉 | main 全宽、两侧各 16px；正文/先修宽度为可用宽；正式先修每条链接独占可换行行；操作至少 44px |

≥1280px 的右栏可以 sticky 于 topbar 下 16px（桌面 topbar 64px，对应 top 80px）。当先修较多或窗口较矮、其高度不能在 topbar 与收起状态底部输入之间完整容纳时，改为正常流不强制 sticky；全列表仍可滚读，不裁切末项。并列启用同时检查实际阅读容器宽度：若因缩放、嵌入或侧区导致不足 932px（680+32+220），立即采用一列，不靠正文缩到 680px 以下硬塞两列。容器查询或等价宽度判断由前端实现。

中窄屏章首先修全部在正文前默认可见。为小节深链接进入时不让先修信息随章首滚走，在 topbar 下设置单行紧凑提示：有先修为“正式先修 N 篇 · 查看本篇先修”，无先修为“无正式先修”。这是返回已展开先修区的定位入口，不是折叠控件；点击仅滚回该篇先修区，不更换篇章、不清除当前链接身份。提示条约 40px，高度随文字换行可扩展；不用固定大块列表占据小屏阅读空间。宽屏右栏已可见时不重复该提示。

小节定位为实际标题预留 topbar 加紧凑提示及约 12px 间距，参考桌面单列 116px、≤760px 122px 的 scroll margin；字体变大或提示换行时应按真实高度处理。初进章首不要滚掉先修，明确小节深链继续定位真实标题，并同时保留先修提示。刷新/后退保持原位置行为，由 QA 独立核。

## 必要身份与上下文

正常当前正文不显示版本/hash/研发能力说明。源版本、hash、来源核对继续在内部以及检索“查看出处”、历史记录、下载身份中保留；设计删减不能跳过其验证。

明确历史正文仍在正文前显示低调但清楚的“历史教材 v10”提示与现有对应当前篇入口。来源失配、标题位置不存在等必要错误仍在当前位置显示，不藏入设置，也不套用当前正文身份。历史页先修按该来源关系呈现，不把 v12 先修当历史正文真实关系。提示使用一般辅助区，避免弹窗打断阅读。

底部问答面板延续已交 `app-v14-dialog-design.md`，右栏不使用 fixed 覆盖正文，也不提高层级盖住问答输入。收起输入的保留空间延续现有 body 底部 padding；问答展开时依用户操作覆盖辅助区属于既有面板行为，仍能收起继续阅读，不因详情布局抢焦点或重发查询。

## 可访问性与领域自查

正式先修辅助区用独立标题及 `aria-labelledby`，列表为真实列表，课程名为实际链接；键盘順序以正文前的先修信息、篇内定位、文章和阅读操作连贯安排，右栏视觉顺序不得造成令人困惑的焦点跳转。小屏“查看本篇先修”为可理解按钮/等价定位动作，定位后让先修标题可见，必要时以可聚焦标题明确当前位置，但不自动朗读全部正文。当前章节名称、长链接和状态文字允许换行，主区和右栏 `min-width:0`，不靠 overflow-x:hidden 掩盖溢出；代码/表格继续各自在原块内横向滚动。

正文行高、16/18/20px 用户字号、图放大、焦点框和既有移动导航不变。按钮/链接保持 44px 操作面积，先修状态不只用颜色表示。源 CSS 与文字交接不构成真实布局验证；前端交付后由测试员核桌面、窄屏、多个先修/无先修、深链、历史及问答受影响行为。

本稿只交布局尺寸、位置、状态和可访问性交接，不编课程、不自定新先修、不重写产品验收，不以设计交付推断完整培养或行业目标已达成。
