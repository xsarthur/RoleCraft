## PLR-AI-006 · AI Agents in LangGraph

资源版本与边界：DeepLearning.AI 当前课程页快照（Intermediate，1h32m，9 个视频、6 个代码示例、1 个 PRO 作业）；课程页未给发布版本/日期。英文课程；beta 限时免费，PRO 作业可能需订阅；中级 Python 为明确先修。课程和 LangGraph 框架许可需分开核对，不能把框架经验泛化为通用 Agent 能力。

**理论机制问题（4）**

1. LangGraph 的显式状态图与普通函数链分别如何表示节点、边、状态更新和终止？请指出一个状态未被合并或重复写入会造成的可观察故障。
2. 在工具调用和 human-in-the-loop 中，暂停点、恢复点和幂等键各解决什么问题？如果工具副作用发生后进程崩溃，哪些状态可以安全重放，哪些必须人工确认？
3. 流式输出、持久化检查点和最终结构化结果之间的契约如何区分？如何避免把部分 token 或旧检查点当成最终答案写入下游？
4. Agentic Search 中“模型决定下一步”与固定工作流的边界是什么？给出至少两个适合固定工作流、两个适合图式循环的条件，并说明评估指标。

**反例**：一个节点在工具成功后先写入“已完成”，随后进程在保存工具结果前崩溃；恢复时按“已完成”跳过工具，最终引用为空。学习者需指出状态不一致、重放策略、补偿/人工介入和应保留的原始失败证据。

**取舍题**：在“固定三步检索流程”和“可循环的 LangGraph Agent”之间选择一种为内部教材检索原型实现；比较可预测性、调试/评估成本、循环失控风险、人工介入和未来变更成本，并明确何时拒绝使用图框架。

**岗位作品（`W-AI-006`）**：隔离 LangGraph 小任务包：状态 schema、节点/边图、工具契约、检查点与恢复说明、来源绑定、超时/重试策略、评估矩阵及未运行项清单。作品必须同时提供固定工作流基线，不能只交框架代码。

**隔离练习（`E-AI-006-S1`）**：本地无网络夹具模拟“检索→工具返回→人工审批→发布草稿”。注入超时、重复回调、旧检查点、空工具结果四种故障；学习者实现或绘制状态转移，记录每次重放是否安全及停止条件。不得使用真实密钥或对外发送。

**失败/边界证据**：保留首次失败日志/状态快照、重复回调前后状态、空引用/冲突来源处理、循环上限触发、人工拒绝后的恢复记录；代码示例未运行须标记 `unrun`。需证明课程示例 API 与当前安装版本是否兼容，不能用课程观看记录代替。

**迁移任务（`U-AI-006-T1`）**：将课程的状态、持久化和人工介入模式迁移到不含真实数据的本地任务队列；只改变一个约束（工具变为不幂等或检查点存储短暂不可用），解释应改的假设、停止/降级策略和需要重新验证的指标。由非作者冻结夹具。

**先修**：Python 中级（课程明确）；函数/异常/序列化、HTTP/工具调用基本概念、任务合同与证据账本；了解 v12 中 Agent 运行闭环、信任边界和评估单元。若无法解释幂等、状态快照或 JSON 结构，先补共同基础与 Python 练习。

**停止条件**：不能区分课程内容与 LangGraph 当前 API；把流式部分当最终结果；无法处理重复副作用、无匹配或人工拒绝；使用真实凭据/外部写入；来源或版本不明。触发任一条件即停止并升级给 AI 生成工程师，保留失败记录。

## PLR-COMP-004 · 欧盟相关市场定义公告 C/2024/1645

资源版本与边界：欧盟委员会竞争总司《Commission Notice … (C/2024/1645)》，CELEX `52024XC01645`，官方公报 C 1645，2024-02-22；2020 咨询页仅为历史背景，不能当现行公告。多语种官方文本可读；本训练使用英文。EUR-Lex 开放访问，转载须遵守法律通知和署名/变更说明；材料是竞争法执法指导，不是法律意见或通用市场规模方法。

**理论机制问题（4）**

1. 公告中的相关产品市场与相关地域市场分别解决什么可比性问题？请用“需求替代、供给替代、地域条件”解释边界证据，并指出仍需案件事实的部分。
2. 数字产品中零价格、数据交换、质量/隐私和多边平台如何影响传统价格替代分析？哪些替代指标不能直接当作法律结论？
3. 为什么市场定义是分析工具而非市场力量结论？说明市场边界、份额、进入壁垒和竞争效果之间的逻辑依赖，列出至少两个不能越过的推断环节。
4. 公告的2024版本取代1997公告意味着什么？如何记录版本、段落引用和后来案件/法院实践对解释的影响？

**反例**：研究员用“面向开发者的 AI 教材网站”作为全球单一市场，仅因两个产品都提供聊天功能就合并；忽略语言、地域、数据保护、交付方式和用户转换成本，并把市场份额直接写成“具有市场支配地位”。学习者需逐项指出证据缺口、过度推断和需补充的可比条件。

**取舍题**：为一个跨境产品选择“窄的功能市场”或“宽的数字服务市场”作为初始研究边界。比较可比性、证据成本、遗漏替代品、误导决策和后续扩展成本；写明这是研究假设还是法律判断，以及何时应请法律专家。

**岗位作品（`W-COMP-004`）**：版本化市场定义矩阵：辖区、产品/服务、用户群、需求/供给替代、地域条件、证据链接/日期、反例、未知项和“不能推出”的结论；附 2024 公告段落映射与历史 2020 页面隔离说明。

**隔离练习（`E-COMP-004-S1`）**：给定三个公开产品页面和两个辖区的脱敏事实卡，分别提出窄/宽边界，标注每项证据属于公告内容、项目观察还是假设；故意缺失价格和地域数据，要求输出 `insufficient_evidence` 与补证计划。不得写成法律意见或对外市场声明。

**失败/边界证据**：保留首次错误边界、被遗漏的替代品、地域/语言证据、公告段落定位、2020/2024 版本混用检查、第三方营销材料与官方事实的区分；若无法获取原文或来源日期，记录停止原因而非猜测。

**迁移任务（`U-COMP-004-T1`）**：同一产品换到第二个辖区，只改变数据保护/支付/供应条件之一；重新给出边界矩阵，说明哪些结论可迁移、哪些必须重做，及何时需要竞争法专业意见。由非作者提供新事实卡。

**先修**：竞品研究员章程；基本产品/地域市场、替代品、可比条件与证据账本；能读官方法律/政策文本并区分规范性语句、观察和推断。不了解竞争法术语时先完成共同基础和术语卡，不要求先具备法律资格。

**停止条件**：把公告当市场规模算法或法律意见；把营销声称当实测；版本、辖区、段落或来源不明；用单一功能/价格证据排除替代品；无法标注未知。触发后停止对外结论，升级给竞品研究员责任人，必要时请求法律专家，保留原判断。

## PLR-BE-003 · Google Cloud Professional Data Engineer Learning Path

资源版本与边界：Google Skills path 16（13 activities；页面仅显示相对“Last updated 5 months”）；认证页单列，考试标准费用 USD 200+税、续证 USD 100+税，考试语言与有效期不属于学习路径字段。路径需登录，视频/文档通常免费，实验可能需订阅/credits；活动语言覆盖不完整。高级定位，认证页推荐 3+ 年经验（含 1+ 年设计/管理 Google Cloud 方案），但无硬性先修。Google Cloud 条款控制内容/实验，禁止复制实验/考试内容。

**理论机制问题（4）**

1. 在数据工程路径中，摄取、存储、转换、编排、分析准备和治理之间的边界是什么？请画出数据从输入到可消费产物的最小可重建链，并标出失败点。
2. 批处理、流处理和微批的延迟、成本、顺序、重复和恢复取舍是什么？如何定义“至少一次/至多一次/有效一次”而不把平台默认行为当保证？
3. 数据质量、血缘、访问控制和加密如何影响任务恢复与审计？当质量门失败时，为什么“继续下游并标记”与“阻断下游”需要不同的业务条件？
4. 云服务托管能力与本地 SQLite/Node 任务的原则如何映射？哪些是可迁移的设计原则，哪些必须在真实 Google Cloud 实验或生产环境重新验证？

**反例**：把学习路径完成和证书报名记录当作云生产能力证明；在本地任务中把一次成功导入称为有效一次，重复请求后出现重复行却没有幂等键、血缘或恢复日志。学习者需指出学习证据、运行证据和生产证据的边界。

**取舍题**：为隔离任务选择托管流处理服务、批处理管道或本地 SQLite/Node；比较数据量、延迟、成本、权限、可观测性、锁定和恢复复杂度，明确云实验费用与无云替身的证据差异。

**岗位作品（`W-BE-003`）**：云数据处理设计包：数据模型、摄取/存储/转换链、任务版本、权限/密钥边界、质量门、幂等/恢复方案、成本假设、可重建验证记录和“云上未验证”清单；证书不计作品证据。

**隔离练习（`E-BE-003-S1`）**：用本地临时库和合成事件模拟重复消息、乱序、部分失败、模式迁移和权限拒绝；实现或详细设计重试/死信/回滚，记录任务版本、输入输出哈希和恢复时间。若使用云实验，必须用临时项目和预算上限，不保存账户/实验数据到仓库。

**失败/边界证据**：保留重复导入、模式不兼容、质量门失败、权限不足、超预算或实验不可访问的记录；区分路径页面“活动完成”、本地运行、云实验和生产监控。不得把认证考试通过当系统恢复证据。

**迁移任务（`U-BE-003-T1`）**：将本地 SQLite/Node 任务迁移到另一种数据形状或限制（例如流量突增或不能使用托管服务）；只改变一个关键约束，重新说明容量/延迟/一致性假设、停止条件及需要真实云验证的部分。

**先修**：SQL/关系模型、事务与索引、基本 Python/Node 或脚本、Linux/HTTP 基础、账户权限和版本化任务；先完成共同基础与 BE 数据合同练习。认证推荐经验不是必须，但高级路径不适合完全零基础直接进入。

**停止条件**：没有临时权限/预算或无法确认费用；把云服务名/认证事实混入路径字段；无法解释重复、恢复、权限或成本；准备使用真实数据/生产账号；实验结果不可重建。触发即暂停云实验，改用本地替身并升级后端数据工程师。

## PLR-BE-004 · Designing Data-Intensive Applications, 2nd Edition

资源版本与边界：O’Reilly 2nd edition，ISBN `9781098119058`，出版月份页面为 2026-02（作者书目另显示 2026-03，差异保留），672 页、14 章；英文、付费/机构授权。第一版网站只作历史背景，不混用章节、命令或示例。版权归 O’Reilly；课程只能链接/合法分配访问，不能复制章节/图表/大段文本。

**理论机制问题（4）**

1. 数据模型、索引、事务、复制、分区和流处理分别解决哪类工作负载/故障？请说明它们组合时的一项互相强化和一项冲突。
2. 一致性、可用性、延迟、可扩展性和可维护性如何形成可测量取舍？为什么“分布式系统更可靠”不能脱离故障模型、恢复目标和观测证据单独成立？
3. 复制、分区和重试如何共同产生重复、乱序、写冲突或读旧数据？给出幂等、版本向量/时间戳或补偿策略中的至少一种，并说明适用边界。
4. 书中通用设计原则与具体数据库/消息系统命令如何区分？如何用第二版章节/段落绑定假设，再用隔离实验验证，而不是把书中结论当本项目运行事实？

**反例**：团队引用第一版章节号和旧数据库命令，声称“启用复制即可保证零数据丢失”，却未定义 RPO/RTO、故障模型、写冲突和恢复演练。学习者需指出版本错配、术语过度承诺和应补的实验/证据。

**取舍题**：为本地持久任务选择单节点事务、复制、分区或事件流方案；比较一致性、运维和恢复复杂度、成本与负载形状，提出可证伪假设和何时不值得引入分布式复杂度。

**岗位作品（`W-BE-004`）**：数据密集型设计记录：工作负载/故障模型、数据模型、索引、事务边界、复制/分区选择、RPO/RTO、迁移/回滚、恢复演练、章节/版本引用和本地实现未验证项。不得复制书籍正文或图表。

**隔离练习（`E-BE-004-S1`）**：在本地 SQLite/Node 临时任务上构造并发写入、重复重试、崩溃恢复和模式迁移；先写假设，再运行可重建实验，记录观察与理论不一致处。没有分布式环境时明确“不模拟”的部分。

**失败/边界证据**：保留首次恢复失败、重复/乱序数据、锁/超时、迁移回滚、RPO/RTO未达成、第一版/第二版引用混用检查；记录书籍访问受限或价格未公开，不以无法访问为理论通过。

**迁移任务（`U-BE-004-T1`）**：换一个工作负载（读多写少改为写多、突发或事件顺序敏感），只改变一个约束；重新选择模型/索引/事务/恢复策略，说明需重测的指标和不能由书本直接证明的行为。

**先修**：SQL 与数据建模、事务/索引基础、并发与网络故障基本概念、当前项目 SQLite/持久任务结构；阅读第二版前先完成术语卡。缺少分布式基础时先做本地并发/恢复沙箱，不能直接承接复杂生产设计。

**停止条件**：版本/ISBN/章节不明；把理论或示例当本项目实测；无故障模型、RPO/RTO或恢复证据；准备复制受版权保护内容；无法区分单节点实验与分布式结论。触发后停止架构承诺，升级后端数据工程师并安排补学/实验。
