## 结论

本轮结论为 **insufficient（无法形成浏览器视觉与交互验收结论）**。远程 HTTP 和静态资源版本可以核对：健康接口返回 200，P0 CSS 与题库数据资源返回 200 且哈希与部署记录一致，服务报告教材 v12、114 道题和 240 个知识点。但当前设计岗位子会话无法取得主会话的浏览器标签，不能把 HTTP、静态数据或 CSS 规则当成实际视觉渲染、键盘焦点、交互状态和四种视口的证据。因此本报告不把顶栏不裁切、题目显示、详情/来源、自评入口、问教材交互或焦点恢复标为通过。

## 必须推进的验收动作

1. 由项目经理协调主会话浏览器重新打开 `http://111.231.8.78/#learn`，固定记录 1280×720、390×844、375×844、320×844 截图和 DOM。
2. 在四个视口逐项核对职业选择、登录/注册入口的可见边界、键盘可达性、焦点环和 `scrollWidth <= clientWidth`。
3. 点击题库并至少展开一题，记录题目、详情、来源和教材链接；再按“先阅读后抽题”流程记录自评入口和题数。
4. 操作任务卡开始、返回、收起/恢复；打开问教材提交 ReAct 问题和无匹配问题；打开移动菜单后用 Escape 关闭并记录焦点恢复到触发按钮。
5. 仍需单独补做读屏、200% 缩放、灰度/对比度、软键盘安全区和迟到响应等未验证项。
