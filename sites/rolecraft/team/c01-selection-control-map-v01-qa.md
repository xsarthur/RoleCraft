# c01 选型控制权视觉稿独立 QA（v0.1）

- 检查对象：`team/visuals/c01-selection-control-map-v01.svg`
- 检查岗位：测试工程师（独立视觉/可读性检查）
- 检查时间：2026-10-15（Asia/Shanghai）
- 检查范围：箭头与文字、连线遮挡、画布裁切、颜色对比、SVG 文字替代；不修改 SVG、不修改教材或应用。
- 方法：XML/SVG 元素与坐标静态检查，按声明的 `viewBox=0 0 1600 1120` 核对边界和相邻元素；未找到本机可用的 SVG 离线渲染器，因此没有浏览器/真实字体渲染证据。

## 结论

当前稿为 `met_with_limitations`。发现一项应在教材或产品接入前修复的明确视觉缺陷：第二条竖向箭头与其说明文字处在同一 x 坐标并发生几何穿越，存在箭头覆盖文字的风险。其他结构检查未发现明确的画布越界；对比度和文字替代在源码层面满足基本要求，但字体回退、实际换行、窄屏布局和真实读者理解尚未验证。

## 发现

### V-01：箭头穿过“控制权”说明文字（严重度 P1）

- 证据：箭头路径为 `M 800 452 L 800 492`；说明文字为 `<text x="800" y="485" text-anchor="middle" class="small muted">控制权从左到右逐步交给运行时</text>`。
- 复现：在 SVG 视口中查看 `y=452–492` 的竖线。文字基线为 `y=485`，`small` 字体为 20px，字形大致覆盖 `y≈466–489`；路径在 `x=800` 穿过文字中心，箭头端点还落在文字基线附近。任何支持 SVG marker 的渲染器都可能显示线条/箭头压在文字笔画上。
- 影响：读者可能把线误看成文字中的竖笔画，或无法快速读取“控制权从左到右逐步交给运行时”。这与用户指出的“箭头覆盖文字”直接对应。
- 修复责任：设计师调整路径或标签布局（例如把标签移到箭头侧方、增加垂直间距，或把箭头拆为不穿越文字的两段）；软件工程师接入时保留修订稿并按设计交接实现。
- 复验条件：静态 SVG 中箭头几何包围盒与文字估计包围盒不相交；至少在实际使用的浏览器/渲染器中检查一张完整图和窄屏布局。

### V-02：下方证据说明可能接近右边界（严重度 P2，需渲染确认）

- 证据：底部正文从 `x=126` 开始，`body` 为 24px；文字为“记录：合格/完整目标合格 · 正确等待 · 错误完成 · 读/模型次数 · 用量 · 端到端延迟 · 未知结果”，在 1416px 宽的底部面板中可用宽度约 1348px。源码没有 `textLength`、换行或 `foreignObject` 约束。
- 影响：在中文字体回退或字宽较大的环境，文本可能逼近右侧边框，窄屏缩放时还可能变成过密的一行。当前只能判定为风险，不能据此确认已裁切。
- 修复责任：设计师决定分行/拆成证据标签；软件工程师在接入时实现响应式排版。
- 复验条件：用目标浏览器和实际字体渲染，确认文字不越过 `x=1508` 面板边界，窄屏不发生裁切或遮挡。

### V-03：小字号和窄屏可读性未验证（严重度 P2，未验证项）

- 证据：来源标记使用 `tiny` 17px，底部说明使用 `small` 20px；交接说明要求窄屏改为纵向/分步，但本 SVG 固定 `1600×1120`，没有响应式规则。
- 影响：教材页面缩放、移动端或学习工作台窄宽容器中，方案卡文字可能缩小到难以扫描；这不是当前桌面画布裁切的已证缺陷。
- 修复责任：产品经理与设计师确定展示方式，软件工程师实现适配，QA 在目标窄屏尺寸复验。

## 已检查通过或未见明确缺陷

- **画布边界（静态）**：背景和主面板覆盖 `0..1600 × 0..1120`；主面板为 `x=48..1552、y=38..1082`。可见文字最高约 `y=102`、最低基线 `y=1065`，未发现源坐标超出 viewBox。
- **主要连线间距（除 V-01）**：第一条箭头 `y=310..356` 位于顶部条件框与判断框之间；第三条箭头 `y=900..932` 位于方案卡底部与证据框之间，源码坐标未穿过其他文字节点。
- **颜色对比（源码估算）**：正文 `#182230`/白底、辅助文字 `#526174`/白底、箭头 `#3c6e9e`/白底均达到常规正文/图形对比度的安全范围；彩色卡片仍配有文字标签，颜色不是唯一信息来源。未做目标浏览器抗锯齿和色觉模拟测试。
- **文字替代**：根 SVG 含 `role="img" aria-labelledby="title desc"`，并有 `title` 与 `desc`；交接文档另有完整“文字替代”段落。接入教材时需确保替代文本仍随图呈现，不能只保留颜色卡片。

## 未验证项与责任

- 浏览器或目标教材阅读器的实际渲染、字体回退、抗锯齿、marker 绘制：设计师/软件工程师修订后由 QA 复验。
- 窄屏/响应式布局和放大后文字可读性：产品经理确认展示规则，设计师提供稿件，软件工程师实现，QA 验证。
- 真实读者是否能正确理解“谁控制下一步”和升级条件：用户研究员按产品门槛采集；本报告不把源码检查当作真人理解证据。
- 内容是否与当前教材版本逐项一致：内容审校员负责独立核对；本报告只检查图中已有文字的呈现风险。
