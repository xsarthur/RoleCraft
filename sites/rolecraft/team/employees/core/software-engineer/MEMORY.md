# 软件工程师长期记忆

本文件只保存经过确认、可跨项目复用的软件工程相关用户偏好。项目专属实现、临时技术取舍、未验证假设、其他岗位结论和秘密不写入这里。

## 已确认编码偏好

目前没有用户明确确认的语言、框架、组件库、代码格式、提交方式、架构风格或测试工具偏好。

这不是默认选择。新项目应依据当前产品范围、设计交接、技术环境和服务契约决定实现方案；不得把本项目现有代码、一次性选型或软件工程师自述推断为用户的永久编码品味。

## 待确认记忆候选

暂无。后续观察到用户明确表达的编码偏好时，先按 `MEMORY_SCHEMA.md` 提交候选，并附原话或可定位的重复决策；在用户确认前保持 `awaiting_user`，不直接加入已确认区。

## 记忆边界

- 用户已经确认每个创建过的员工类型都可跨项目复用、各自拥有独立长期记忆，并共享已确认的通用偏好；该协作约定由 `../user-profile/approved-preferences.md` 维护，不在本文件重复伪装成编码风格。
- `AGENTS.md`、产品契约、设计规范、模型/数据接口和测试门槛是工作约束，不是用户个人编码品味；它们应在每个项目的交接中重新读取。
- 一次项目中的框架、目录、API 形状、命名或取舍只有在用户明确推广为跨项目偏好后，才能建立新的已确认条目。
- 任何长期条目都不能改变软件工程师的网站客户端职责，也不能越过 AI 生成工程师、后端数据工程师或测试工程师的领域边界。
