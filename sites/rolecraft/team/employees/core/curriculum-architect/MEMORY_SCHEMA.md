# 课程架构师长期记忆条目格式

## 用途

此格式用于记录经过证实、能够跨项目复用的用户教材偏好或课程协作约定。它把用户明确确认的长期约定、项目局部课程决定、岗位的专业判断和待验证假设分开，避免把一次性教材改动误写成永久教学品味。

## 必填字段

| 字段 | 要求 |
| --- | --- |
| `id` | 稳定唯一标识，例如 `CA-MEM-0002`；替代旧条目时保留旧 ID 和关系。 |
| `title` | 简短描述记忆内容，不把推测写成事实。 |
| `statement` | 可执行、可观察的偏好或协作约定；区分用户要求、课程规则和岗位建议。 |
| `kind` | `curriculum-architecture`、`learning-sequence`、`textbook-spec`、`practice-and-rubric`、`handoff-format`、`evidence-threshold` 或 `cross-project-memory`。 |
| `evidence` | 用户原话、明确决策、重复项目记录或可定位的独立证据；至少注明来源和日期。 |
| `scope` | 适用的岗位、课程类型、项目、学习阶段、版本和限制；跨项目必须写清条件。 |
| `confidence` | `confirmed`、`strong`、`tentative` 或 `unknown`。只有用户直接确认或团队规则明确允许的证据，才可使用 `confirmed`。 |
| `confirmation_status` | `user_confirmed`、`awaiting_user`、`inferred`、`superseded` 或 `rejected`。 |
| `version` | 语义版本，例如 `1.0.0`；内容变化时递增并保留变更说明。 |
| `recorded_at` | 首次写入日期，使用 ISO 日期。 |

## 推荐字段

| 字段 | 用途 |
| --- | --- |
| `constraints` | 不得越过的边界、例外、重新确认条件和相关授权。 |
| `non_inferences` | 明确列出没有从证据推导出的相邻教学偏好或能力结论。 |
| `last_reviewed_at` | 最近复核日期；长期未复核的条目应降级或重新确认。 |
| `related_projects` | 证据所在项目；项目名称本身不等于跨项目推广授权。 |
| `supersedes` | 本条替代的旧条目标识；没有则写 `none`。 |
| `change_log` | 版本、变更原因、证据和确认来源。 |

## Markdown 模板

```markdown
### CA-MEM-XXXX — 标题

- **偏好/约定**：
- **类型**：`textbook-spec`
- **证据**：来源、日期、可定位记录
- **范围**：
- **限制**：
- **未作出的推断**：
- **置信度**：`tentative`
- **确认状态**：`awaiting_user`
- **版本**：`0.1.0`
- **记录日期**：YYYY-MM-DD
- **最近复核**：YYYY-MM-DD
- **关联项目**：
- **替代条目**：`none`
- **变更记录**：
```

## 状态与升级规则

1. 新观察先写入当前项目交接或 `memory-proposals/`，状态为 `awaiting_user` 或 `inferred`，不得直接写入本文件的“已确认条目”。
2. 用户明确说“这是我的长期教材偏好”“以后教材都这样”或等价语句时，记录原话、日期和适用范围，可升级为 `user_confirmed`。
3. 多个项目出现一致行为可以提高置信度，但不能替代用户确认对个人教学品味的授权；课程团队的推断也不能冒充用户偏好。
4. 记忆冲突时不静默覆盖：创建新版本或新条目，标记旧条目 `superseded`，说明冲突证据和适用范围变化。
5. 任何条目都不能改变 `AGENTS.md` 的岗位边界、用户授权、原能力目标、产品门槛或独立测试职责。
6. 删除或降级记忆时保留审计记录；被拒绝、过期或仅限项目的偏好不能继续用于新项目。

## 读取与写入协议

- 新项目开始：读取角色说明和已确认记忆，只把与当前课程范围匹配的条目作为建议输入，并核对项目自己的 `AGENTS.md` 与版本交接。
- 任务进行中：把新观察写到项目记录，附证据、范围、不确定性和可能影响的岗位。
- 任务结束：提交记忆候选，等待用户确认后再更新本文件；候选不得替代课程交付、内容审校或实训评估。
- 跨岗位共享：只共享已确认且与对方职责相关的条目；课程架构师不替教材研发员、内容审校员或实训评估员创建其专业记忆。
- 记忆条目若影响课程结构、正文规格或评价量规，须在项目交接中注明影响范围，并由对应责任岗位按新版本复验。
