## 一手来源核验

以下为当前实际读取范围，均未以规范替案例授合规或效果结论。

- [W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：已读320 CSS px/400%等价、二维例外和200%区别；章节10/17/19表述基本相符。
- [W3C Target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：已核24×24 CSS px及例外；44/36明确是教学选择，不是WCAG通用门槛。
- [W3C APG Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：已核初始焦点、Tab循环、Escape和回焦；不能证明真实模态实现。
- [W3C Text spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)：已核1.5/2/.12/.16与语言适用性；正文未把它当默认排版强制值。
- [W3C Status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：已核非抢焦点状态的程序可识别要求；不推出所有流式字符都应播报。
- [W3C Grid](https://www.w3.org/WAI/ARIA/apg/patterns/grid/)：已核交互grid的键盘责任；正文未把所有只读表格强制grid。
- [GOV.UK moderated testing](https://www.gov.uk/service-manual/user-research/using-moderated-usability-testing)：已读任务、招募、观察与主持边界，支持19方法背景，合成结果不代表研究执行。
- [GOV.UK analysis](https://www.gov.uk/service-manual/user-research/analyse-a-research-session)：已读原始观察/发现/行动分离，支持04的证据链。
- [GOV.UK whole problem](https://www.gov.uk/service-manual/design/map-a-users-whole-problem)：已读跨组织旅程与接续问题，18未把公共服务规则当退款业务规则。

- [Microsoft HAI](https://www.microsoft.com/en-us/research/publication/guidelines-for-human-ai-interaction/)：已读2019研究18项指南及研究范围；14仅称方向参考，不冒称澄明验证。
