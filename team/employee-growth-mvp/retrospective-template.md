# 两周 MVP 复盘卡模板

复制为 `employee-growth-mvp-{周期}-retrospective.md`。每周填写一次轻量卡，两周结束填写完整卡。复盘只记录事实和可执行改进，不把完成复盘写成能力认证。

| 字段 | 填写 |

| 复盘范围 | `T1`、`T2`、`T3` 或单项任务 |
| 复盘日期 | `YYYY-MM-DD` |
| 项目经理 |  |
| 责任岗位 |  |
| 独立复核人 |  |
| 关联合同/交接/账本 |  |

- 开始时的 Growth 基线/证据：

- 这次确实完成了什么：

## 3. 双轨结果（分开填写）

- 状态：`passed` / `failed` / `insufficient`

### Growth

- 成长目标（原文引用）：
