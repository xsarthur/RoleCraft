# Rolecraft 1.0 产品最终验收记录

- **验收日期**：2026-10-16（Asia/Shanghai）
- **验收岗位**：产品经理
- **目标环境**：`http://111.231.8.78/#learn`（远程单开发环境）
- **发布身份**：`rolecraft-1.0`
- **产品结论**：`overall_not_met`
- **限定范围结论**：`met_within_scope_for_learning_workbench_and_retrieval; qa_followup_required`

## 结论

当前远程版本已经可以作为 1.0 的学习工作台候选使用：页面能进入 Agent 学习路线，首页突出一个当前任务，任务卡显示“未开始”和“开始学习”，题库/复习/自评/P01 入口都可发现；“问教材”抽屉能完成有出处的教材回答、版本展开、来源定位和无匹配反馈。职业选择对 `React` 给出了 ReAct 与前端 React 两个澄清选项，并在确认动作前展示教材版本、索引版本、语料 hash；未登录时确认会进入登录要求，没有静默改变职业。

产品 1.0 的完整验收仍未成功。题库页面实际显示“题库资料暂不可用；不会用演示题替代”，因此 V1-04 失败；当前浏览器只观察到“未开始”任务状态，没有独立复验中断/已浏览恢复、窄屏/键盘/200%缩放/读屏、浏览器内 P01 提交恢复和登录后确认写入证据。上述缺口不能由接口 200、源码分支、静态设计或工程自检关闭。

产品定位按用户最新决定执行：提供行业知识、教材定位、练习和面试准备支持，帮助用户更从容地应对市场面试；不承诺就业、职业认证、岗位胜任、真人专家认可或行业领先。

## 当前版本实际观察

### 已观察通过的范围

- 远程页面返回 HTTP 200，页面、响应头、健康接口和内容目录均带 `rolecraft-1.0`。
- 页面视觉上有固定主导航、当前任务卡、版本徽章、本机记录边界和问教材入口。当前任务卡显示：`当前任务 · 未开始`、`开始第一篇 · 认识Agent工程`、`开始学习`。
- 主页一次点击可到达题库、复习、自评检验和 `进入 P01 练习`；复习页和自评页会诚实显示当前没有可用题或未掌握题，不伪造成绩。
- P01 页面展示练习 ID、教材版本、正文来源、`sourceSha256`、`submission_id`/`previous_submission_id`、七个作品字段、本人自述、证据引用、五类记录层级和五种作品工作流状态。
- 问教材抽屉可打开/收起，成功查询“解释 Agent 控制循环如何恢复”时显示教材简答、来源链接、`阅读这一节`、原文摘录以及展开后的教材版本、教材身份、索引版本、语料 hash、来源路径、原稿 hash 和稳定定位。
- 无匹配查询“量子化学实验设备维修”显示“没有找到匹配的教材内容”，并提供改写和打开课程目录的恢复动作；接口状态为 `no_match/related_uncovered`，没有编造答案。
- 职业选择对 `React` 显示“Agent 的 ReAct 方法”和“前端 React 框架”两个澄清按钮；选择 ReAct 后展示 `Agent 开发者`候选、匹配理由、教材/索引/语料身份、只读浏览入口和“查看并确认”。
- 选择确认时，未登录浏览器被引导到“登录学习账户”，页面明确说明登录后才保存职业和学习记录；没有发生匿名静默写入。
- 远程接口实测：`/api/health`、`/api/content/catalog`、`/api/content/chapter/p01-mvp`、教材推荐/查询、版本失配、上下文缺失、进度写入、P01 版本化提交及自评记录均有响应；P01 记录返回 `artifactVerification=not_fetched_or_executed`、`professionalStatus=unreviewed`、`humanStatus=not_started`，客户端伪造评审结论会返回 `client_verdict_forbidden`。

## 完整目标与责任

原八门槛不因本次远程部署或产品验收改变：真实模型生成和可靠生产交付仍为 `fail`；用户价值、教学质量、比较优势、学员创造和运营经济仍为 `insufficient`；就业、职业认证、岗位胜任、真人专家审核、真实学习效果和行业先进性没有证据。

当前最影响 1.0 收口的缺口是题库数据/页面可用性（客户端 + 课程/内容数据），其次是四态任务恢复、P01 浏览器提交流程、职业确认的登录后写入、固定反例和响应式/无障碍独立复验（客户端、后端/检索、设计、QA 分别负责）。项目经理负责协调各岗位按原验收 ID返修，保留首失败记录，返修后按原例和受影响范围复验；不能用“接口成功”或报告完成替代产品达标。
