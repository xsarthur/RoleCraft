# v12 市场题集驱动教材补齐：产品口径冻结

日期：2026-10-11。责任岗位：产品经理。状态：评估前冻结，供课程、作者、审校与QA执行。本文件不是教材审核结果，不改变原八门槛。

## 范围与目标人群

本轮交付是市场样本、当前基线复核、实际新教材、练习作品关联、独立审校和复验的完整链条，不能停在研究报告或计划。默认目标为具备软件工程和大模型应用基础、准备进入或承担初中级 LLM Agent 应用工程工作的学习者；这是一项明确的产品范围选择，不是市场调研结论。基础不足者经诊断进入现有补学入口；高级分布式架构、跨组织协作等专题另标层级，不把所有高级面试题设为初级门槛。专业正文仍遵守 TEXTBOOK_WRITING_STANDARD.md，既有零基础培养目标通过先修路径保留。

保留双目标：专业岗位能力，以及从真实问题出发独立创造、评估和迭代产品。面试题是外部缺口探针，不能替代真实问题、用户证据、已有方案、差异化假设、实现、可比评估、真实使用反馈和迭代的产品训练链。

仅新增 textbooks/v12/ 及 team/textbook-v12-*；旧教材、原八门槛和历史报告保留。不改网站、服务、账户数据，不上传发布、外部联系或付费调用。原54/36/10仅历史参考，须核收到v10版本后逐题复核，不能原样授新结论。

## 样本与判定冻结

原100题为不可改题意的固定回归集，分母恒为100。新市场题单独统计，记录中英文来源、来源类型、发布日期或未知、访问日期、岗位层级、原题意、去重组及同源关系。转载不累计独立频次；题库、候选人自述不认证为企业真题；“热门”只能按样本内证据说明。官方技术文档用于核事实，不作为面试频次证据。

每题按完整问法判断，不能通过删子问改善分类：

| 等级 | 条件 |
| --- | --- |
| 充分支持 | 仅当前正文即可组织覆盖全部主要子问的回答；机制、取舍、实现或验证方法有实质证据，专属框架/协议题必须具备相应契约与版本语境。 |
| 部分支持 | 能支持部分实质子问，但关键机制、对比、操作、契约或必要事实缺失。 |
| 未覆盖 | 无实质教学；只有术语、标题、外链或无关通用原则不能算覆盖。 |

正文允许跨章组合，但不能由审校者补出教材未教的关键连接。外链全文、应用源码、其他版本、历史报告和评审者知识均不补分。仅改善导航不会自动提升等级。版本敏感行为需明确版本/规范与核查日期，未知不得按最新有效推定。争议先保守归类并留理由。

Q10、Q99及新增同类真实项目/事故经历题，教材最多“部分支持”；另外记录方法教学支持程度与学员个人证据状态。不得把真实经历题改写成假设案例来获得充分。其他操作题的正文充分只表示教法完整，不证明学员已掌握。

原集、新增集、保留变体集各自分别报告充分/部分/未覆盖及总数，不混合稀释原100缺口；充分加部分不可称完整可答率。题目层级和市场频次与课程必要性分列。

## 五维成熟度与结论边界

不用任意加权总分，不新增“多少题即入行”的阈值。各维度记录当前证据、局限、待补证据和责任人：

| 维度 | 所需证据 | 可作结论与限制 |
| --- | --- | --- |
| 知识广度 | 逐题及能力分布、岗位层级、关键缺口 | 只描述样本内正文覆盖，不外推整个市场 |
| 教学深度 | 机制因果、核心实现、执行轨迹、取舍、失败分析的独立审校 | AI静态审校不等于真人专业认可 |
| 可执行性 | 环境版本、命令、输入输出、正常/失败路径实跑 | 仅授实际运行例；伪代码、外部契约、旧例另列 |
| 迁移与项目训练 | 未公开变体、独立任务规格、能力—练习—作品链 | AI变体审计不是学员实作成绩 |
| 真实学习与求职结果 | 真实学员作品、独立评价、用户反馈、求职证据 | 缺失保持未验证，不以覆盖率推算录用 |

用“已形成何种范围的教材支持、仍缺何种证据”描述成熟程度。正文支持作答、学员能作答、能独立实现、岗位胜任与获得录用五者不得替代。完整培养和行业先进目标按原 product-gates.json 判定，不因本轮报告或题目覆盖改善自动通过。

## 章节与交付验收

课程架构师把缺题归并为能力缺口，定义章节位置、先修、核心问题、正文/练习/作品去向；保留原12模块、24目标、48知识点和产品训练路线。作者实际融入正文，不能只附题解合集或营销式摘要。

每个新增/扩写核心教学单元须让读者重建关键机制：输入、状态、控制转移、前提和不变量；提供足以体现核心逻辑的接口/数据结构/实现、正常与失败轨迹；对可行方案给出有条件的取舍；以触发条件、信号、处置与复验说明失败；提供分层任务及可核验作品要求、参考分析。不是机械字数、代码量或固定栏目配额。核心逻辑不得藏进无契约黑盒，版本 API 不得编造。新概念与旧正文需交代先修、关联和冲突处理，不能靠重复堆砌。

必要新增安全离线例须实际交付并由QA运行正常与关键失败路径；不为“可运行”冒充真实LLM/MCP/A2A/沙箱基础设施调用。若例子只展示策略模型，应明确不提供系统级隔离或真实远端保证。全体代码标记可执行/伪代码/外部依赖及实际验证状态，旧例不因复制获得新运行结论。

内容审校独立读当前正文，QA独立复核原100和全部新增题、必要新增例、组装/导航/来源及版本；发现问题由作者返修，原例复验。QA另准备未向作者公开题面的同能力变体，首测在作者冻结后进行；首测结果保留，若用于返修则该题不再声称未见，另取新变体或明确已暴露。能力范围可交作者，题面不提前交付。无需把新增高级题全部补成核心必修，但每个残余必须有领域理由、责任人和下一步，不能静默删除。

本轮交付验收至少包括：市场来源表；改前/改后逐题矩阵；五维诊断；真实新教材与阅读入口；能力—正文—练习—作品映射；作者交接；独立内容审校和QA；缺陷返修/复验；剩余缺口与八门槛复盘。不能以创建文件数代替实际内容验收。

## 逐题矩阵契约

每行至少：id、set、完整question、sourceRefs、sourceType、publishedDate、accessDate、dedupGroup、roleLevel、capabilities、baselineVersion、baselineEvidence、baselineSupport、missingSubquestions、finalVersion、finalEvidence、finalSupport、methodSupport、personalEvidenceStatus、owner、rationale、reviewer、dispute、retest。

证据包含文件路径、章节/段落定位、短引文及版本哈希；改前与改后证据不得混用。最终计数从逐题结构化记录生成，全部题可追溯，不用关键字命中代替语义判断。基线不等于历史分类，差异须解释。

## 责任及自查

竞品研究员负责来源和市场证据；课程架构师负责能力与学习路径；教材研发员负责正文与返修；内容审校员负责独立技术深度；QA负责当前交付和示例验证；真实学员作品交实训评估员、用户反馈交用户研究员；PM协调并总结版本、原因、责任人与复验。岗位不交叉代写/自审。

本岗已读 AGENTS.md、既有100题产品与QA、专业写作标准和原八门槛；只交范围与验收口径，未编教材、执行测试或决定最终分类。新教材充分率、真实学习效果及完整目标均待各责任岗位当前证据。规则现冻结，后续不能为改善结果而降低定义。

## 市场新增能力分层预交接

按能力而非尚未冻结的题号分层：asyncio取消/超时与并发、Python可变对象/装饰器、LRU和内存泄漏基础属于软件先修；基础欠缺者须有实质补学或明确既有教学位置，不能只列“应会”。向量距离、ANN与召回权衡、增量索引及文档/PDF-OCR摄取、结构化输出及验证、跨语言检索/会话话题切换属于应用岗位核心；Transformer和推理基础作为理解上下文、输出与成本行为的必要先修，深度训练推导不设普遍初级门槛。大规模推理服务优化列高级；客户技术交接按角色拆分，部署条件、已知限制、复现说明和运维责任是核心交付能力，售前架构统筹和组织级方案另列高级。具体题目若跨层级必须保留完整题意，主层级与子问层级分别记录，由市场报告到达后核对，不预授其支持等级。

所有必要知识缺口须实质教学处理；不要求原100全部充分，但不能用“框架未实测”或“真实接口未调用”掩盖本应补齐的正文解释。正文支持度与行为执行证据分别评价。源保护由QA记录，PM行政记录不代替独立保护检查。

## 本批101–114分层确认（市场稿交后）

已只读核对 textbook-v12-market.json 的14道完整题，编号101–114连续唯一；其独立分母为14，不与原100或QA变体合并计覆盖率。该报告自称便利样本并保留转载、访问和高级JD局限，产品口径不赋予市场热度认证。未新增分数或通过率阈值。

| 题号 | 产品学习层级 | 边界 |
| --- | --- | --- |
| 101 | 先修强化，初中级应用必需 | asyncio并发、取消与清理须实教，不扩为运行时研发 |
| 102–103 | 基础补学 | Python对象/装饰器与LRU独立编码，不用先修标签豁免教学去向 |

| 114 | 核心交付方法＋中高级客户场景 | 重建、评测、决策记录和接手验证方法是核心，客户组织协调属进阶；原题是方法设计而非本人经历，不自动套Q10/Q99上限，真实接手结果另记未验证 |

市场原level作为来源描述保留，以上是产品学习分层，不能覆盖或伪装来源岗位信息。作者应为必要核心/先修缺口提供实质内容，高级专题合理教学深度由课程规格交接；所有未充分题仍须透明列明原因、责任人和后续。
