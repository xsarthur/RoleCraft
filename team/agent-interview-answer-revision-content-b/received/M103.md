# M103｜实现容量受限的LRU缓存，说明get/put复杂度，并给出容量为零、覆盖已有键和淘汰次序的测试。

答案版本：interview-answers-v1.0.1。完整参考解析；示例及测试计划未由本稿执行。

LRU淘汰“最近最久未访问”的条目。哈希表负责从键找节点，双向链表负责访问顺序；get命中和put覆盖都把节点移到最新端，新键超容量时删除最旧端。单纯列表查找/删除虽然能实现顺序，却会使访问变成O(n)。

以下完整实现使用环形哨兵，root.next是最旧、root.prev是最新。适用Python 3.14；键必须可哈希且哈希/相等行为在缓存期内稳定；容量按条数，零表示禁用，缺失抛KeyError，合法值None与缺失不混淆。代码为本稿教学实现，**未执行**。

```python
class Node:
    __slots__ = ("key", "value", "prev", "next")
    def __init__(self, key=None, value=None):
        self.key, self.value = key, value
        self.prev = self.next = self

class LRU:
    def __init__(self, capacity):
        if type(capacity) is not int or capacity < 0:
            raise ValueError("capacity must be nonnegative int")
        self.capacity = capacity
        self.nodes = {}
        self.root = Node()

    def _unlink(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _append(self, node):
        tail = self.root.prev
        node.prev, node.next = tail, self.root
        tail.next = node
        self.root.prev = node

    def _touch(self, node):
        self._unlink(node)
        self._append(node)

    def get(self, key):
        node = self.nodes[key]
        self._touch(node)
        return node.value

    def put(self, key, value):
        if self.capacity == 0:
            return
        if key in self.nodes:
            node = self.nodes[key]
            node.value = value
            self._touch(node)
            return
        node = Node(key, value)
        self.nodes[key] = node
        self._append(node)
        if len(self.nodes) > self.capacity:
            oldest = self.root.next
            self._unlink(oldest)
            del self.nodes[oldest.key]

    def keys_old_to_new(self):
        keys = []
        node = self.root.next
        while node is not self.root:
            keys.append(node.key)
            node = node.next
        return keys

    def __len__(self):
        return len(self.nodes)

def must_miss(cache, key):
    try:
        cache.get(key)
    except KeyError:
        return
    raise AssertionError("expected miss")

zero = LRU(0)
zero.put("a", 1)
assert len(zero) == 0
must_miss(zero, "a")
cache = LRU(2)
cache.put("a", 1)
cache.put("b", 2)
assert cache.keys_old_to_new() == ["a", "b"]
assert cache.get("a") == 1
cache.put("c", 3)
must_miss(cache, "b")
assert cache.keys_old_to_new() == ["a", "c"]
cache.put("a", 9)
assert len(cache) == 2 and cache.keys_old_to_new() == ["c", "a"]
cache.put("d", None)
must_miss(cache, "c")
assert cache.get("d") is None
one = LRU(1)
one.put("x", 1)
one.put("x", 2)
assert one.get("x") == 2
one.put("y", 3)
must_miss(one, "x")
print("LRU assertions passed")
```

不变量是字典里的节点与链表节点一一对应，root前后链接闭合，节点访问顺序由旧到新，条目数不超过容量。get/put包含常数次指针操作；在通常哈希假设下平均O(1)，极端哈希冲突不能承诺最坏O(1)。诊断遍历keys是O(n)，不用于核心访问。存储O(capacity)，但值可能很大，条数上限不等于字节上限。

上面断言分别定位零容量、访问刷新、覆盖不增量、淘汰次序和None值边界。还应测试非法容量、交替访问，以及每次操作后前后指针一致。多个线程同时操作需保护整次更新，跨await也须有明确一致性；这个类没有实现线程安全、TTL或权限失效。缓存受保护知识时键还要包含源版本和范围，返回前核当前权限。

生产可采用标准库OrderedDict的move_to_end与popitem(last=False)表达重排；手写链表是解释实现，不是推荐所有项目重复造轮子。[OrderedDict文档](https://docs.python.org/3.14/library/collections.html#ordereddict-objects)，核查于2026-10-14。
