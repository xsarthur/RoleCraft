## 本轮必要行为

1. 在当前 Agent 开发职业语境下，用户输入裸术语 `react`、`ReAct` 或 `REACT`，应返回包含上述真实提及的小节，并可直接打开原文。不能因术语没有落入预置意图类别就判无匹配。英文大小写变化不改变同一术语的可发现性。
2. 术语查找的候选必须来自实际正文，引用和小节目标仍按原合同核验。对其他已出现的专业术语，同样允许实际文字提及成为候选；常见英文大小写变化不应使真实提及消失。宽泛、多处出现或有多义的术语可以澄清或按当前任务排序，不能造不存在的章节。路径、构建元数据及代码依赖包名本身不能作为教材正文的推荐依据。
3. `React 前端框架`、`React 的 JSX 和 Hooks` 等明确指向前端框架的表达，不应因拼写相同而推荐 Agent ReAct 段落。当前教材没有足够相应内容时，返回诚实无匹配或明确澄清，不编写框架回答。单纯大小写不能用来区分这两种意义；应采用明确语境。
4. 当用户同时问“React 是前端框架还是 Agent 的方法”而无法确定学习目标时，返回澄清，区分前端 React 与 Agent ReAct；未选择前不能把其中一个当用户确定意图。当前职业中的裸术语可依据第 1 条推荐真实提及，不要求每次额外询问。
5. 明确否定的术语不是肯定需求。“先不看 ReAct，想知道中断后怎样接着执行”不得让 ReAct 提及成为主推荐，应继续处理恢复意图。只有排除表达而无肯定目标时，可澄清想学什么或无匹配，不抓被排除术语硬推。
6. 原自然含义推荐、多意图、未知表达和无匹配行为保留。直接术语命中可以补充检索，不能把原自然语言功能替换成纯关键词查找。模型模式和外部调用状态按实际执行如实返回，不因增加术语通路宣称调用了外部模型。
