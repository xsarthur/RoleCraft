## 必须实现的单职业工作流

### 1. 不对话也能完成系统学习

首次进入 → 首页默认路线图 → 点击实际课程节点 → 阅读 v12 正文 → 进入配套题目 → 查看教材参考分析 → 自记未掌握 → 回到对应正文 → 在记录继续或复习。起点自选只用于用户偏好和检索上下文，不生成能力诊断或强制解锁。

路线图应有可理解的学习主干、节点、分支和顺序连线，30 篇均可达；基础 / 实作等分组沿用已交课程数据和正式顺序，不由产品/设计/前端另编先修。具有缩放、移动/拖拽、状态筛选和恢复全图控件，并保留键盘可用的等价目录。不能只把旧六张阶段文字卡换个标题叫路线图。目录和路线必须共享同版正文、小节、状态和关联题。

路线三态为“已学习（访问过） / 有未掌握题 / 未学习”；这是本人浏览和标记，不是经评估的专业掌握。橙色状态优先于访问绿色；颜色之外同时有文字或图标。单元只有部分小节有访问时不能静默把整篇全部小节记为已学。历史 v10 足迹也不能变成当前 v12 状态。

正文是页面主体，不用弹窗装正文；可提供折叠目录和原小节定位，桌面内容宽度与字号由设计交接。图、表格、围栏、原文引用及安全示例链接完整保留，代码只查看/下载，不执行。末尾或上下文区提供配套题目及实作入口，题目数量来自真实映射；无关联题显示“此知识点暂没有配套题”，不造 3—5 道题凑数。

### 2. 从题库查缺并回溯课程

题库 → 课程/知识点筛选 → 选择一题 → 答案详情 → 查看教材参考分析和关联知识点 → 跳至对应 v12 小节 → 返回原题继续。题库可从列表直接标“未掌握”，不会点进详情才看到此操作。默认未标注，会的题可以直接跳过。

状态遵循：未标注 → 未掌握（主操作）；已标未掌握时提供“已掌握（自评）”；再次点击当前状态可取消；已掌握题可以重新标未掌握。操作即时反映在题库、答案、学习记录及课程节点，同一题 ID 不建立互相矛盾的多份状态。界面整体说明这些状态为本人自记，不以其授予能力认证。

答案区本轮用“教材参考分析（原文摘录）”，而非冒称已按 PRD 在线生成并固化的“标准答案”。题面与正确源引用稳定、可核；不显示伪输入频率、点击热度、必考保证或真实企业原题认证。可以按冻结题组 / 课程顺序 / 题号排序，明确无真实平台频次数据；如果以后接入实际排序须另验证。

### 3. 回访复习与本次自评检验

学习记录默认“已学习”，按当前版本实际最近访问排列，可继续原位置和做其配套题。三个快捷入口的空态有明确可执行去向：没有足迹去看路线，没有未掌握题显示无待复习，没有已学关联题显示先学课程，不生成假记录。

“复习”逐题显示本人未掌握题 → 查看参考分析 → 仍未掌握 / 已掌握自评 / 学知识点 → 下一题，支持上/下一题；标已掌握后从未掌握列表移除。列表取消标注和重新标记保持同步。

“检验学习结果”只从当前 v12 已访问/已学习知识点实际关联、可自评的题中去重抽题，默认 5 道，可选 5 / 10 / 20；不足就使用全部实际可用题并说明数量，不重复补足，也不抽未学习知识点或需真实经历的题。逐题先想/输入本人答案，再查看参考分析，再“我答对了（自评） / 我答错了（自评） / 跳过”。结束显示本次自评答对/答错/跳过与回溯入口，不显示历史累计掌握率。错题可由本人选择加入未掌握，不能后台无提示授予掌握。自评不等于机器评分或专业考试。

### 4. 底部唯一辅助输入保持学习上下文

首页、课程路线/目录、正文、题库/答案、学习记录及实作子页底部常驻一个“查教材”输入入口，个人设置除外。不在主壳和页面内再摆同功能独立大输入框。展开为底部辅助面板，正文仍能保持上下文；收起按钮、点击外部非操作空白处、Esc 可以收起并正确回焦。移动端可展开更大面板，但不能遮住关闭按钮。

提示语随页面变化，例如“描述想解决的问题，查对应教材”“对这一节有疑问？查相关解释”“想补这道题的知识？查教材”；用“查教材”匹配当前真实能力，不暗示可以凭空生成答案。身份与意图快捷标签只在课程首页展开面板出现，语句选择引导现有路线/题库/教材，不包装为已完成 AI 诊断。

继续用实际 `POST /api/content/recommend` v12 BGE 混合内容检索及来源验证，保留自然表达、多意图、否定、React 消歧、无匹配、不可用和重试；推荐包含原文与具体节。不得用原型 `getAIResponse` 或计时器模拟成功，不把未命中变成一段假 AI 回答。需要配置的生成/外部检索诚实说明当前未接入；未来接入另验。

查询中用户能立即收起、读教材、切页；提交时上下文随该次请求固定，结果不能被后来页面重新标成另一题/另一节。就绪后只在底部输入条显示“教材推荐已就绪”之类轻提示，不自动弹面板、全屏遮罩或 Toast 抢焦点。迟到响应不能覆盖后来提交的查询；语料/source 失配仍拒绝肯定推荐。面板保留本次及有限查询历史，不把教材推荐冒称多轮辅导记忆。

### 5. 0 到 1 实作和既有记录保留

用户从 0 到 1 创造产品的目标继续保留。课程中问题发现、任务验收、MVP 与作品复盘章节有清楚“实作”入口，学习记录下方有“项目记录”子区，可保存已有问题/证据/结果/差距/下一步字段，并回到相关教材；这是真实本地自述档案，不是自动评审。既有项目记录不能因导航移除消失，`#projects` 等旧链接仍能到同一项目子页或明确兼容入口。

原“能力标准、原课程地图、产品达标复盘、电子员工复盘、单章生成研发、历史教材/项目/概览”等退出首页、主导航和正常正文的高频操作区，集中在设置的“历史资料与研发记录”可折叠子区。教学本身的原引用、适用边界与先修仍可在正文展开查看；产品专业报告和八门槛不删除。不要为了减模块把用户旧数据或阅读导航一起抹去，也不要把研发报告页当正常学习必经步骤。

## 兼容和能力边界

保留 `rolecraft-v1`、v10 `rolecraft-learning-v11`、v12 `rolecraft-learning-v12` 的原值及原来源身份。新增题状态/测验/设置用独立追加结构或键；不在首次加载自动改写旧值。v12 正文没有变化，已有同源/hash 合法 v12 阅读可以继续使用，不能把 v10 同 ID 的阅读视为 v12；损坏原值仍能导出且明确无法解析。新增失败时输入留在内存，提示导出，不显示保存成功。

现有 `#home` / `#path` / `#learn` 与 `#learn/agent/<unit>/<section>` 仍有可达目标，无版本阅读显示当前 v12；显式 `?version=textbook-v10` 保持历史正文和只读身份。旧笔记/收藏/访问、作品、自查和达标复盘各保留真实性质；未知节或版本不能静默映到其他内容。旧研发/历史路由直接访问仍能显示本页的历史说明与返回设置/当前学习入口。新增题库、详情、复习和检验的路由由工程交合同，刷新、返回、复制深链可保持目标。
