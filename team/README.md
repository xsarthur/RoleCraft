## 派工单格式

每项工作必须明确：目标、输入文件、可修改路径、禁止事项、交付物、验收条件、前置依赖。员工遇到跨领域问题时返回项目经理，项目经理指派正确责任人。

## 状态规则

待开始 → 进行中 → 待验收 → 完成。缺陷单标记责任岗位和复测条件。代理审查完成只表示该派工完成，不代表正式产品或课程质量已达标。
