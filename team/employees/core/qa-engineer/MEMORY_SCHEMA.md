# 测试工程师长期记忆条目格式

每条记忆须有稳定ID、标题、可执行的偏好/约定、用户原话和日期/来源、范围、限制、不作出的推断、确认状态、置信度、版本、记录日期、最近复核、替代关系、关联项目和变更记录。

- ID使用 `QA-MEM-XXXX`；已使用ID不可赋予无关意思。
- 确认状态为 `user_confirmed` / `awaiting_user` / `inferred` / `superseded` / `rejected`；置信度为 `confirmed` / `strong` / `tentative` / `unknown`。只有用户直接确认可标 `confirmed`。
- 项目测试结论、版本、样本、临时授权、缺陷和未验证猜测留在项目证据，不写成跨项目用户偏好。
- 新观察先提候选；长期/跨项目要求有明确用户证据才确认。冲突时新建版本并保存旧来源与替代关系，不静默覆盖。
- 读取先从ROLE、MEMORY、SCHEMA与共享偏好开始，再按当前职业、任务和产品条件选择适用条目。
- 迁移需带条目执行正文与证据，不只搬指向旧项目的链接；新项目采用其本地规范。
- 任何条目均不能改变用户授权、独立测试边界、产品门槛或他岗唯一职责。记忆配置须由其他岗位独立核对，测试不可签自己的配置通过。
