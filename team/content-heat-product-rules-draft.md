# 内容版本与热度规则讨论草案

日期：2026-10-12。责任岗位：产品经理。状态：供后续讨论，具体规则待确认。

本稿只整理本聊天的方案；未改程序、数据库、教材或历史报告，未运行测试、未安排其他岗位。它不代表当前功能已经实现或验证。

## 已明确的方向与范围

- 学习笔记从新方案范围中移除；现有代码和历史数据本轮不操作，移除功能不等于删除既有记录。
- 未来支持教材持续迭代、多职业，以及章节关联的面试题等拓展内容；这不改变当前先完善一个职业的阶段范围。
- 需要统计章节、知识点、面试题的使用热度，包括对话实际引用的部分，用于筛选热门模块和提高其评审、更新频次。
- 用户接受上述建议并授权产品经理后续整理规则；当前仍只讨论方案与设计，没有开发、扩展协作或自动更新发布授权。

## 建议规则

### 1. 内容身份与版本

| 对象 | 建议管理方式 |
| --- | --- |
| 职业与学习路线 | 职业关联适用教材、章节和题目；顺序、必修及先修由路线表达，允许跨职业复用内容。一个职业对应一本教材还是多本组合，待确认。 |
| 教材与发布版本 | 教材保留稳定身份；每次发布固定章节顺序、章节修订版本及关联关系，旧发布版不被新版覆盖。 |
| 章节与小节 | 章节使用稳定ID，正文修订另有版本；引用定位到该版本的具体小节或片段。章节号、标题和锚点不能单独作为长期身份。 |
| 知识点 | 独立稳定ID与必要修订，和章节／小节多对多关联。未明确标注的知识点不由统计系统猜测归属。 |
| 面试题与其他拓展 | 独立ID、修订、来源和适用范围；可关联多个职业、章节、知识点，关联记录“考查”“先读”“延伸”等含义及适用版本。 |

正文按教材发布版本保持稳定，拓展可独立更新。引用、事件和内容关联均保留来源版本；检索索引及向量是内容派生物，需绑定同一来源。章节拆分、合并或知识点定义发生实质变化时保留映射，不能仅凭同名跨版合并统计。

### 2. 分别计量使用行为

| 指标 | 计量含义 |
| --- | --- |
| 访问 | 用户主动打开对应章节、知识点或题目；预加载不计主动访问。 |
| 阅读 | 实际展开／有效停留等阅读信号，和访问分开；具体识别条件待确认，不推导学会或读完。 |
| 检索命中 | 内容进入检索候选，用于分析检索行为，不能当回答引用或用户需求。 |
| 回答引用 | 最终实际展示给用户的回答所引用的具体内容；模型提议、未展示草稿、失败回答不计。 |
| 引用点击 | 用户实际点击已展示引用进入原文，独立于回答引用。 |
| 作答／看解答 | 面试题提交作答与查看解答分别统计；不由查看解答推导完成练习。 |

引用绑定回答ID、内容ID、修订／教材发布版本和原文位置。同一回答重复引用同一章，章级引用一次；不同小节分别计量，同一小节重复引用不重复增加该回答的小节引用数。知识点只在片段具有明确关联时汇总；多知识点、多章节汇总不能简单相加解释为总需求量。点击次数与点击人数分开，合法重复点击不等于运输重试。

“平台使用热度”与“市场面试热门程度”分开。后者需要来源、采集时间、适用职业及判断依据，不从本平台点击量直接推导。

### 3. 事件、汇总与统计口径

保留最小行为事件，再生成可重算的日汇总。建议事件记录：唯一事件ID、行为类型、发生时间、内容稳定ID与版本、职业／教材上下文、必要的账号或匿名标识；引用事件另有回答ID及引用定位。日汇总保留访问、阅读、命中、引用、点击、作答、看解答等独立指标，以及统计口径版本，不先合成单一热度分数。

- 事件ID保证重试、重复上报只入账一次；同回答引用按上述内容身份去重。刷新、重复打开是否构成新访问，需后续确定会话口径，不能临时混用。
- 登录访问人数按账号去重，称“账号数”；匿名按匿名标识去重，称“匿名标识数”。不以设备、匿名标识冒充真实学习者；匿名转登录的合并规则待定，不直接相加宣称人数。
- 日汇总的每日独立人数不能直接相加为一周独立人数；跨日窗口需要对应窗口去重。
- 提供时间范围筛选，增长比较使用相邻等长窗口，并显示样本量与覆盖情况；上期为零不强行给百分比。统计时区、常用窗口待确认。
- 新旧版本既可看各版，也可按稳定ID看历史；比较需注明上线时长、内容／关联变化、流量及推荐位置差异，不把曝光差异解释为内容质量变化。
- 测试、自动访问及异常重复流量应有可说明的排除口径；具体识别规则、数据保留期和可查看权限待后续讨论。

本用途不需要存完整对话、API密钥或作答正文；必要标识只用于关联、去重和汇总，不因此扩大采集范围。

### 4. 从热度到更新优先级

支持按职业、教材版本、章节／知识点／面试题、时间范围筛选，分别查看使用最多、增长较快和待更新模块。展示指标来源，避免目录靠前或模型偏好造成的热度被误读。

内容过时、用户无帮助反馈、待修订问题、最近审核／更新时间作为独立质量信号，与热度一起供人工安排优先级。高热度模块可更频繁评审，但是否改动由具体问题与内容审核决定。反馈需要保留对应回答、引用版本或内容位置；负反馈本身不自动证明原文错误。

建议闭环：使用统计 → 筛选模块 → 查明问题并评审 → 修订、审核、发布新版 → 在可比窗口观察使用与反馈。热度不等于正确性、教学效果、职业胜任或行业先进；低热度也不代表基础或安全内容可以忽略。

暂无统一评分权重、固定热门阈值、更新周期或自动发布规则。本草案不改变既有产品八门槛，不关闭完整培养／行业目标的证据缺口。

## 后续待决策

1. 职业采用单本教材还是多本／路线组合；内容复用及拆分合并的版本映射规则。
2. 阅读信号、访问会话、匿名转登录、统计时区、常用窗口、保留期与统计权限。
3. 先提供分指标人工筛选，还是以后建立有依据的综合排序；评审频次与发布流程另行确认。
