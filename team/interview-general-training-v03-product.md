# 面试准备上层模块与范围组卷产品交接 v0.3

责任岗位：产品经理  
日期：2026-10-16（Asia/Shanghai）  
状态：产品信息架构、组卷流程和验收合同；待设计、客户端、后端数据、内容检索、课程与测试岗位交接  
前置版本：`interview-general-training-v02-product.md`（保留为历史版本，不覆盖）

## 1. 本轮产品决策

用户明确面试准备是一个上层模块，不能把通用流程内容直接铺在面试题顶部。面试准备至少提供以下并列入口：

1. **精选面试题**：浏览产品维护的精选题目列表，按题目直接练习或加入练习试卷；
2. **通用流程专项训练**：练习自我介绍、理解与澄清、结构化回答、处理追问、向面试方提问、结束与复盘；
3. **按范围组卷**：用户选择题目和通用环节的范围、题量与练习方式，预览可用内容后生成一份可保存和继续的面试演练试卷。

同时保留一个独立的**面试方法文章**学习入口。文章是学习材料，不自动成为试卷题目；用户可从文章、精选题、通用流程和试卷结果互相跳转。

“试卷”在本版本中的产品含义是可回放的面试演练集合，不是学校考试、招聘方评分表或录用预测。默认不产生统一分数，不把完成题数、文章阅读或 AI 自评转化为职业认证。

## 2. 顶层信息架构

```text
面试准备
├─ 精选面试题
│  ├─ 题目列表/筛选
│  ├─ 题目详情
│  └─ 直接练习 / 加入试卷
├─ 通用流程专项训练
│  ├─ 六阶段选择
│  ├─ 口述/文字练习
│  └─ 文章学习与读后练习
├─ 按范围组卷
│  ├─ 选择范围
│  ├─ 预览与调整
│  └─ 生成的面试演练试卷
└─ 面试方法文章（独立学习入口）
   ├─ 主题列表/搜索
   └─ 文章详情/开始练习
```

面试准备首页的默认首屏显示上层模块标题和三个主入口卡。精选面试题可作为默认主入口，但不能让通用流程大面板遮挡题目。文章学习作为次级但始终可达的入口，显示 2–4 张精选文章卡和“查看全部文章”。

题目练习和专项训练仍保持 v0.2 的数据与视觉隔离。题目首页最多显示一张紧凑的“通用流程专项训练”入口卡；完整六阶段说明、文章正文和组卷配置不在题目上方展开。

## 3. 入口一：精选面试题

### 3.1 列表定位

精选面试题是产品维护的可浏览题目集合。它帮助用户先按岗位、轮次、题型和主题发现高价值练习，而不是让用户面对空白筛选器。列表可以包含精选标记、推荐理由和题目来源，但不使用“必考题”“命中率保证”等文案。

每张题目卡至少显示：

- 题目 ID、题干和题型；
- 适用职业/方向、面试轮次、主题和难度（若已绑定）；
- 来源状态、教材版本和可定位章节/小节；
- 建议练习时长和回答模式；
- 当前用户状态：未练习、进行中、已练习、需复习（若用户授权显示历史状态）；
- `直接练习`与`加入试卷`两个动作。

列表支持按职业、轮次、题型、主题、难度、来源状态和练习状态筛选，并支持搜索题目 ID、标题和关键词。过滤结果为空时显示无匹配原因、改写/清除筛选入口，不生成不存在的题目。

### 3.2 题目详情

题目详情以回答为主操作，包含题目来源、适用上下文、练习说明、口述/文字回答、转写确认、AI 分析（若配置可用）和相关通用流程链接。相关链接只传递题型上下文，例如“这道项目题可练：结构化项目回答”，不把通用建议覆盖进题目答案。

用户可在详情中：

- 直接开始一次独立练习；
- 加入当前试卷草稿；
- 查看来源原文和文章；
- 返回精选列表或范围组卷。

## 4. 入口二：通用流程专项训练

通用流程专项训练延续 v0.2 的六个主题与课程交接：

1. 自我介绍；
2. 理解与澄清；
3. 结构化回答；
4. 处理追问；
5. 向面试方提问；
6. 结束与复盘。

用户可以从任一主题开始，不要求先完成六阶段。每个主题提供`阅读文章`、`开始练习`和`加入试卷`三个动作；加入试卷的是一个明确的通用流程任务实例，不是虚构面试题。文章正文、练习、录音、转写和 AI 反馈的边界沿用 v0.2 与 v0.2 课程交接。

专项训练首页显示：继续上次、六阶段卡、推荐文章和查看全部文章。单阶段练习页一次只聚焦一个阶段，不在面试题首页展开完整长面板。

## 5. 入口三：按范围组卷

### 5.1 进入方式

用户可从面试准备首页进入“按范围组卷”，也可以从精选题、通用流程阶段或题目详情点击“加入试卷”。

- 首页进入：创建一份新的范围配置；
- 精选题进入：将一题加入当前试卷草稿，可继续浏览并添加；
- 通用流程进入：将一个或多个阶段任务加入草稿；
- 题目详情进入：保留当前题目上下文后返回组卷配置；
- 已存在草稿时：提示继续编辑、另存新卷或放弃草稿，不能静默覆盖。

### 5.2 范围选择器

范围选择分为必选、可选和高级设置。选择器应先展示可用数量和内容身份，再允许生成。

**必选或默认明确项**：

- 职业/方向（可选择当前已确认职业或暂不指定）；
- 练习来源：精选题、用户已加入题目、通用流程任务，至少选一种；
- 题量或任务数量；
- 练习模式：口述、文字或混合。

**可选筛选项**：

- 面试轮次：筛选/电话、技术、项目/行为、系统设计、终面或未知；
- 题型：概念/原理、项目/行为、系统设计、排障/场景等；
- 主题/能力；
- 难度（只有题目有可靠绑定时可选）；
- 通用流程阶段：自我介绍、澄清、结构化、追问、反问、结束复盘；
- 教材/内容版本或来源集合；
- 是否加入追问任务；
- 总时长和每题/每阶段建议时长；
- 固定顺序或按范围内可复现的排序。

高级设置允许用户：

- 从已收藏/已加入题目中组卷；
- 排除已练习题或指定题目 ID；
- 设置开场和收尾任务是否必含；
- 选择是否先显示文章学习建议；
- 保存配置为可再次使用的范围模板。

不应把“用户薄弱项”“难度高低”当成未经确认的能力结论。若使用练习历史排序，必须显示已读取的记录范围并获得用户授权。

### 5.3 范围预览与校验

用户点击“预览试卷”后，系统显示：

- 将生成的章节结构与顺序；
- 每类题目/通用任务的可用数量与已选数量；
- 题目 ID、通用任务 ID、标题、来源版本和预计时长；
- 可能的重复、缺失来源、未绑定难度和未确认情境；
- 总题量、预计总时长和回答模式；
- 需要用户调整的筛选条件。

校验规则：

- 选定题量大于可用数量时，停止生成并提供减少题量、放宽筛选或添加通用任务的选项；默认不重复题目；
- 没有任何匹配时，返回 `no_match`，保留用户选择，不生成空试卷；
- 题目元数据冲突、来源版本失效或内容检索不可用时，显示相应状态，不用标题相似度补造题目或来源；
- 题目有来源但通用任务只有通用建议时，分开显示身份；
- 用户未指定职业/轮次时，标记为未指定，不由系统猜测。

### 5.4 生成试卷

用户确认预览后点击“生成面试演练试卷”。生成动作必须冻结一次范围快照，不因之后题库或文章更新而静默改变已生成试卷。每份试卷应能被用户识别和恢复，至少展示：

- 试卷名称（用户可改写）；
- 创建时间和最近更新时间；
- 试卷版本与内容语料版本；
- 范围摘要（职业、轮次、题型/主题、阶段、题量、时长、模式）；
- 分段结构和每项 ID；
- 来源状态与可定位入口；
- `继续练习`、`调整范围生成新卷`、`删除`动作。

推荐的章节顺序为：

1. 可选开场：自我介绍；
2. 用户选择的精选面试题；
3. 可选结构化/追问任务；
4. 可选向面试方提问；
5. 可选结束与复盘。

系统不得为填充题量自动插入未选内容。若用户选择混合模式，界面要明确哪些是题目、哪些是通用流程任务。

## 6. 试卷状态与练习流程

试卷状态与单项回答状态分开记录。状态定义如下：

| 状态 | 含义 | 用户动作 |
| --- | --- | --- |
| `draft` | 已开始选择范围或从列表加入内容，尚未生成 | 继续配置、清空、删除草稿 |
| `ready` | 已生成且范围快照完成，尚未开始 | 开始、调整后生成新卷、删除 |
| `in_progress` | 至少开始一项回答 | 继续、暂停、查看已答/未答 |
| `paused` | 用户主动暂停或离开后保留 | 继续、放弃、删除 |
| `submitted` | 用户提交本次演练，等待反馈/复盘 | 查看状态、等待或重试可用服务 |
| `reviewing` | 已有转写/反馈或用户进入复盘 | 查看来源、重答、记录行动 |
| `completed` | 用户完成本次约定的练习范围和复盘动作 | 查看总结、复制/重用范围、再练陌生题 |
| `abandoned` | 用户明确放弃；历史回答仍保留删除策略 | 查看或彻底删除 |

生成试卷不等于完成试卷；完成试卷不等于能力达标。未回答、跳过、转写低置信、分析不可用和用户自评应分别记录，不能合并为“失败”或“通过”。

单项回答沿用现有语音/文字状态，语音必须先核对转写再分析。试卷总结只列可观察的练习证据：已答/跳过、来源查看、反馈状态、用户标记和下一步文章/练习，不输出未经校准的录用概率或职业等级。

## 7. 面试方法文章入口

文章学习作为面试准备的独立次入口，在首页显示精选文章卡并提供“查看全部文章”。文章中心按以下主题组织：

- 自我介绍；
- 理解与澄清；
- 结构化回答；
- 处理追问；
- 向面试方提问；
- 结束与复盘。

每张文章卡显示标题、主题、摘要、预计阅读时间、适用阶段、来源状态、版本和`阅读/继续阅读/去练习`动作。文章详情显示正文、教学示例、失败与边界、来源定位、不确定性和下一步练习；文章默认不加入试卷，用户主动点击“加入练习试卷”后才进入草稿。

文章推荐可以从精选题、通用流程阶段、试卷反馈和题目结果跳转，但必须携带内容版本和来源身份。未绑定、无匹配、文章缺失或检索不可用时诚实显示状态，不能生成不存在的文章。

## 8. 数据与版本边界（产品合同）

产品、客户端和后端需将以下对象分开：

- `question`：精选题或用户已加入的题目，保留题目 ID和原来源；
- `general_task`：六阶段通用流程任务，不伪装成题库题目；
- `article`：文章或教材分节，仅用于阅读和练习引导；
- `paper_draft`：尚未生成的范围选择；
- `paper`：范围快照已冻结的面试演练试卷；
- `paper_attempt`：某次实际练习尝试；
- `answer_attempt`：单题/单任务回答及其转写、反馈、用户标记。

`paper`至少需要保存：试卷 ID、试卷版本、创建时间、`scopeSnapshot`、内容语料版本、项目项顺序、每项来源状态、练习模式和状态。后续教材或题目更新只影响新试卷或用户主动重新生成；旧试卷保持可追溯。删除试卷/尝试时，音频、转写、反馈和文章阅读记录按用户选择及既有保留规则分别删除，不把正式题库或教材源一起删除。

内容检索只读接口可提供候选题、通用任务、文章和来源；组卷模块不得自行从模型文本生成题目。无配置的 AI/ASR 服务必须显示不可用，并保留文字练习或文章学习入口。

| IGP-07 | 组卷前显示可用数、项目明细、来源状态、预计时长和缺口；超量、无匹配、版本失效不静默生成 | 四类校验反例记录 |

| IGP-10 | 已生成试卷按章节区分题目、通用任务和可选文章建议；不自动插入未选项目或重复题目 | 混合试卷 UI 和项目清单对照 |

| IGP-12 | 文章中心按六主题提供卡片、筛选、详情、来源、版本、阅读状态和去练习/加入试卷动作 | 两篇文章详情与来源逐项核对 |
| IGP-13 | 试卷历史、题目回答、通用任务练习、文章阅读记录分别可继续、删除和返回，不覆盖原题库或用户旧记录 | 隔离账户数据和删除证据 |
| IGP-14 | 无来源、无匹配、歧义、检索不可用和未授权历史记录均显示诚实状态，不编造题目、文章、公司流程或用户经历 | 固定反例的 HTTP/UI 快照 |
| IGP-15 | 试卷总结只报告可观察练习证据，不输出录用预测、职业认证、统一能力等级或“必然加分”结论 | 文案审校清单和独立内容 QA |
| IGP-16 | 面试准备首页、列表、组卷、试卷练习、文章详情在键盘、窄屏和屏幕阅读器下可操作，焦点/状态清晰 | 设计与测试独立可访问性证据 |

## 10. 岗位交接与限制

- **产品经理**：维护上层入口、范围字段、状态迁移、试卷身份和验收样例；不编写教材正文或客户端代码。
- **课程架构师**：维护通用任务与文章的学习目标、能力映射和必要先修；文章正文状态按课程交接执行。
- **设计师**：先交面试准备上层导航、三入口卡、范围选择器、试卷状态和文章入口视觉稿；以视觉层级表达“题目、通用任务、文章”三种对象。
- **软件工程师**：实现入口、筛选、组卷和状态消费，不自行重定义题意、来源或评分标准。
- **内容检索工程师**：维护题目/任务/文章候选召回、来源定位和版本校验，只读交付给组卷模块。
- **后端数据工程师**：负责试卷草稿、快照、尝试、删除、恢复和权限边界，不删除正式题库与教材源。
- **AI 生成工程师**：仅在另行授权和配置后接入 ASR/反馈；不可用时保留诚实降级。
- **测试工程师**：独立执行 IGP-01–16，分别检查入口层级、组卷范围、状态恢复、来源绑定、文章学习、隐私删除和可访问性。
