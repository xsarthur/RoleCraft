# Rolecraft 1.0 UI/UX 视觉与交互验收

- **验收岗位**：设计师
- **验收时间**：2026-10-16（Asia/Shanghai）
- **目标环境**：远程单环境 `http://111.231.8.78`
- **页面**：`http://111.231.8.78/#learn`
- **实际方法**：CUA 浏览器实际打开与操作；视觉截图与无障碍树均来自远程页面。未修改代码。
- **视口证据**：桌面约 1280×720、窄屏 390×844、最窄 320×844。
- **依据**：`DESIGN_COMMUNICATION_STANDARD.md`、`design-v1.0-learning-workbench.md`、`product-v1.0-scope.md`。

## 结论

本轮 UI/UX 在已实际观察的核心范围内为 **insufficient（限定范围通过，仍有缺口）**。桌面主任务、教材阅读、问教材结果/无匹配/等待、移动导航和焦点恢复均已在远程浏览器中看到；320px 顶栏出现关键职业/登录入口被裁切，题库数据当前返回不可用，自评当前为 0 题。屏幕阅读器、200% 缩放、灰度/对比度工具、软键盘安全区和真实用户理解未验证，不能写成完整视觉与交互通过。

## 视觉与交互优点

- 暖白背景、白卡、深棕正文和金色主按钮形成稳定层级；主任务卡以边界和位置突出，不依赖颜色单独传达状态。
- 桌面路线图、当前任务和问教材入口的空间关系易辨认；“题库/复习/自评检验/进入 P01 练习”在主卡下方一次点击可见。
- 问教材在等待、结果和无匹配状态中均保留输入和恢复动作；结果带原文来源和版本身份，符合来源优先原则。
- 移动端导航折叠后仍能到达首页、课程、题库、复习、自评、记录和设置；问教材收起后焦点恢复到触发入口。

## 必须推进的缺口

1. **窄屏顶栏裁切（P0 视觉交互缺陷）**：320px（390px右侧也有明显压缩）下把职业选择和登录/注册改为导航菜单内或单行可换行布局，确保可见、可聚焦且不横向滚动。责任：软件工程师；产品确认入口策略；QA按 320/375/390 复验。
2. **题库与自评数据可用性（P0 产品阻力）**：题库返回“资料暂不可用”，自评可用题为 0；当前空态诚实但不能视为题库/复习/检验能力完成。责任：产品经理、课程架构师、后端数据工程师；完成后由 QA 重新验收。
3. **无障碍与极端环境证据**：完成完整键盘 Tab/Shift+Tab、焦点可见、200% 缩放、灰度/对比度、读屏、软键盘安全区和长标题/hash检查。责任：测试工程师，设计师配合复核视觉。
4. **未观察状态**：已中断、已提交证据、服务失败、版本失配、歧义澄清和迟到响应需在当前远程环境实际操作后补证据；不得由静态源码或历史报告继承。

## 证据边界

本报告只记录本轮远程浏览器中看见和操作到的页面。视觉截图是当前会话视口的实际渲染，不代表所有设备、浏览器、读屏或真实用户结果。设计验收不授予职业能力认证、就业结果、真人专家认可或行业先进结论。
