# 运营分析员 · 成本与运行证据交接

2026-10-10；唯一领域：运营经济分析。依据 AGENTS、SPECIALISTS、product-gates、prototype-0.3 审计及生成/后端交接。`operating_economics`仍证据不足；本文件为采集核算规格，没有实际调用、账单、质量或维护结果，不关闭缺口。

## 记录契约与空模板

后端按事件时间持久保存；生成岗位提供供应商实际调用字段，运营岗位做对账分析。所有待采集值均为 `null`，记录集合初始为空 `[]`；缺失与实际零分开。

| 记录 | 待采集字段 |
| --- | --- |
| 关联 | jobId、attemptId、chapterId、artifactVersion/hash、inputHash、任务/生成配置/资料/提示版本 |
| 调用 | provider、modelActual/version、providerRequestId/responseId、本地callId、开始/结束时间、HTTP/错误码 |
| 用量 | input/output/cacheRead/cacheWrite tokens、其他计费单位、usage原始证据引用、usage是否完整 |
| 恢复 | retry序号/原因、前次attempt、超时、取消、供应商执行状态、chargingStatus、去重/关联依据 |
| 运行 | 排队/调用/验证/保存/总耗时、最终任务状态、持久化与恢复结果、失败类别 |
| 质量 | 产物版本、内容审校/独立验收状态及证据、返工次数、人工审核分钟、审核人及执行日期 |
| 费用 | 币种、价格来源/生效日/版本、估算值、账单条目与周期、实际金额、分摊规则、对账差异 |

`chargingStatus`采用待确认/已计费/确认未计费；失败、超时和未知执行不可默认免费。重试保留所有尝试；供应商请求ID为空时不得补造或仅凭相同文本去重。缓存token口径、计费单位及价格适用范围须核清，不能重复计入输入量。

## 核算与预算

usage是用量证据；按有效价格得到估算费用，实际账单是财务证据，两者分别保存。账单不能细分到调用时标注“分摊”，保留周期、方法和未分配额，不冒充逐次实际费。税、折扣、币种及汇率依据单列；未知部分报告待确认金额范围，无法确定则保留未知。

总成本＝模型/检索/运行存储费用＋人工审核维护工时×经确认工时单价＋其他已确认费用；避免账单与估算重复相加。每章版本成本包含失败、重试、返工；每成功交付成本＝同批次全部成本÷满足预定质量与交付条件的成功数量，零成功时未定义，不填0。成功草稿保存不等于质量通过。

同批次记录尝试及任务成功率、验收通过率、返工率、未知状态数量、排队与端到端耗时分布；写清样本量、起止时间和分母，终态缺失单列。人工审核未计时则经济核算不完整。

预算模板：`scope/version/currency/sample/qualityCondition/costLimit/latencyLimit/reliabilityLimit/maintenanceLimit/approver/approvedAt`均为空，交产品经理在试点前确认，不自定阈值。对照为实际或估算值与对应预算之差；预算或账目缺失时仅报缺证，不判通过。

## 维护、交接与复验

生成工程师维护调用与usage证据；后端数据工程师维护任务完整性、恢复和存储日志；运营分析员负责价格版本登记、周期对账、成本归因及异常清单，项目经理分派实际维护执行任务。每次维护保留责任人、变更版本、时间、工时、故障及复验引用。

日志不含密钥、会话令牌、个人档案或教材原文；账户用受控匿名标识，账单与原始证据限制访问，导出仅脱敏引用，保留期限待确认。

待输入：已确认试点与预算、真实调用/任务日志、价格及实际账单、计时和质量审校结果、维护记录与授权读取范围。本轮未读凭据、未开服务、未推荐价格、未操作付费或对外发布。领域自查已覆盖失败收费、缓存口径、质量分母、未知与零及估算/账单分离。

交产品经理确认预算及判定条件，交两位工程师落实日志接口；测试工程师独立抽样重算、核对账单总额/未分配额、重试不漏计和重复不多计、空usage/超时收费/零成功及脱敏。真实运行和质量证据齐备后重审该门槛；当前整体未达标结论不变。
