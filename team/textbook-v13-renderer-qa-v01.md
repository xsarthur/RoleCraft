## 关键结论

当前 v13 文件是独立 Markdown 试读稿，尚未进入当前学习工作台语料/渲染链。工作台当前由学习服务返回 v12 语料（`dist/learning-v13-data.js` 的 `corpusVersion` 为 `textbook-v12`），因此用户无法从现有产品入口看到 v13 的中段视觉优化或 v13 代码折叠行为。

渲染器目前能把 Markdown 图片转换为带 `alt` 的 `figure`，也提供基础表格、引用和键盘可聚焦代码块；但当前代码围栏统一输出为展开的 `.lw-code`，没有按行数生成 `<details>/<summary>`，也没有实现 Mermaid 图的渲染或明确的图形降级组件。v13 正文中的 Mermaid 和 `text` 图示会按普通代码/文本处理，不能作为中段图片出现。

因此本轮用户指出的“开篇之后仍是大片连续文字、没有穿插其他颜色或图”在当前产品中可以复现为产品缺口：Markdown 中段虽写了 Mermaid/文字视觉卡，客户端未将其转为图；只有每篇开头的一张 SVG 图片具备图片渲染路径。

## 逐项检查

### 1. 长代码默认折叠

**状态：未实现，阻塞。**

工作台 `markdown()` 在代码围栏关闭时始终输出：`.lw-code > span + pre > code`，没有行数阈值、摘要、`details`、展开/收起状态、深链目标或状态持久化。v13 只有 `02-task-acceptance.md` 的 YAML 片段手写 `<details>`，而该 Markdown 解析器不执行/保留任意 HTML，产品渲染无法依靠这段标记完成折叠。

需要产品、设计、开发共同确定并交接：阈值（当前编辑约定为 11 行及以上）、默认状态、摘要文本、关键输入/输出是否在摘要中、展开后的滚动/焦点行为、刷新与深链语义，以及脚本不可用时的静态可读性。测试尚未能执行行为复验，因为客户端实现尚未交付。

### 2. 开篇后中段少量视觉内容与颜色

**状态：未实现，阻塞用户反馈验证。**

v13 源文在若干中段加入 Mermaid 或 `text` 代码围栏，但工作台未实现 Mermaid，且 `inline()` 只将 Markdown 图片识别为 `figure`；因此这些中段内容不会显示为图形卡片。当前每篇仅有开头一张 SVG 图片链接可进入图片路径。中段应提供经过产品/设计确认的静态 SVG/PNG（带邻近说明和文字替代），或实现 Mermaid 的安全渲染/服务端预渲染与降级方案。颜色需有文字/形状辅助，不可作为唯一状态表达。

### 3. Mermaid 与文字降级

**状态：部分具备，未达到要求。**

源文包含 Mermaid 围栏和文字示意，但当前 renderer 会把围栏视为普通代码块；没有 Mermaid 图形、错误提示、静态降级图或“查看文字版”控件。若保留 Mermaid 源码，应至少提供产品认可的静态降级图或可读文本，并在脚本/样式不可用时保留顺序、节点和状态含义。

### 4. 键盘与读屏

**状态：基础能力存在，新增折叠/中段图能力未验证。**

当前工作台为图片放大按钮提供按钮名称和 `alt`，代码 `pre` 有 `tabindex="0"`，表格使用 `role="region"` 与 `aria-label`。但尚无代码折叠控件，因此无法验证 `summary` 键盘操作、焦点回收、`aria-expanded`/`aria-controls`、读屏摘要是否准确；Mermaid/中段图也没有已实现的图例、文字替代或错误降级节点可供复验。

### 5. 窄屏布局

**状态：未验证。**

源码静态规则中 SVG 图片有 `width:100%; height:auto` 的工作台样式，表格有横向滚动；但 v13 未接入当前页面，不能验证中段图、折叠摘要和代码块在约 760px/更窄宽度下是否裁切、覆盖文字或造成横向溢出。必须在真实页面嵌入尺寸下复验，不能以 SVG 源码或桌面截图替代。

### 6. 脚本/样式不可用

**状态：未验证；当前 Markdown 文件本身可读，但应用语义未定义。**

独立 Markdown 保留图片链接、Mermaid 源码和代码文本，理论上可读；但产品尚未确定脚本不可用时是否直接展示原图、文字版和全部代码，或如何提示图形未渲染。折叠若依赖脚本，应确保 HTML 原生 `<details>` 仍可展开，关键内容不因脚本失败被隐藏。
