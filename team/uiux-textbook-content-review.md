- 第 1—3、7—9、12 章能区分教学假设、观察、推断、决定、设计提案和未运行结果；README 与作者交接没有把灯塔案例当现有产品证据。

## 问题登记

### UIUX-C01 — 12 章概要不能满足 26 单元核心交付（P1，open）

- 位置：README 的课程架构关系说明；author-handoff 的作者完成范围；course-architecture 第 6 节及 reading_order。
- 发现：README 和交接已说明尚未逐单元写完 26 个独立深读/实作文件、离线夹具、题目冻结和未知任务复验；课程架构和产品验收要求每个核心单元都有问题、边界、机制、正常/失败路径、可编辑或可运行证据、分层练习、先修迁移与来源。
- 影响：不能将本稿目录或 12 章练习解释为 26 单元已交付。AI 不确定性、控制/解释、多模态、生态、MVP、未知任务等单元只有压缩段落或被提及。
- 责任：教材研发员按课程架构师规格拆分/补齐；课程架构师维护主映射和先修；QA 后续核文件与状态。
- 修正与复验：保留 12 章概要标签，另交 26 单元文件或阶段性交付矩阵；每单元绑定正文位置、正常/失败示例、练习、来源和未运行边界。复验逐项对照 reading_order，不能只数章节标题。

### UIUX-C02 — AI 状态、字段和组件契约互相矛盾（P1，open）

- 位置：正文第 84—88、110—145、166—176、226—249 行。
- 发现：Recommendation 有 confidenceLabel 和 createdAt，但 ResultCard 没有置信/限制字段；ResultCard 有 source-checking/blocked，而 RetrievalState 没有对应状态，也没有低置信、来源冲突、流式、取消、重试、人工接管状态。RetrievalState.result 要求 excerpt 为 string，正文同时规定 excerpt 可以缺失。流程写了取消、超时和重试，但图和类型没有转移；状态表允许继续阅读与取消本次查看，却没有查询后台生命周期和迟到响应规则。
- 影响：学习者无法从同一契约重建低置信原因、来源核对、取消后迟到结果、重试是否生成新 queryId、编辑/人工接管是否保留版本。
- 责任：教材研发员负责正文/伪代码一致性；课程架构师确认 15—17 单元覆盖；AI 生成/检索工程师交接正式字段。
- 修正与复验：建立单一状态机，统一三种模型的字段，明确 excerpt 可选性、evidenceStatus/uncertaintyReason、版本/位置和 queryId 生命周期；补齐 cancelled、retrying、source_checking、low_confidence、handoff 路径或明确映射。状态图、表、伪代码和文案逐边对照，必要时 QA 运行确定性夹具。

### UIUX-C03 — 规范来源没有放在正文邻近主张处（P2，open）

- 位置：sources-and-interview-map 第 8—14 行；正文第 184—208、260—284 行。
- 发现：来源表登记 WCAG、WAI-ARIA、ATAG、NN/g、Material 3、Carbon，但正文直接使用无障碍、ARIA、WCAG 和启发式论断，没有邻近链接或版本锚点。TEXTBOOK_WRITING_STANDARD 明确要求来源链接放在所支持主张附近。
- 影响：读者无法区分规范要求与作者建议，版本复核也无法定位支持关系。
- 责任：教材研发员；课程架构师维护来源规则；QA 核链接和版本。
- 修正与复验：正文首次提出外部规范时放邻近链接/成功准则，明确本篇建议与规范要求；抽查每项外部事实，确认链接直接支持邻近句。

### UIUX-C04 — ATAG 2.0 适用范围写宽（P2，open）

- 位置：sources-and-interview-map 第 11 行。
- 发现：W3C ATAG 2.0 的对象是 Web 内容创作工具：一部分要求工具界面对残障作者可用，另一部分要求工具支持作者产出更可访问的 Web 内容。它不是设计文件、Figma 交接包或任意设计资产的通用合规标准。
- 影响：设计师交接包、设计工具本身和最终 Web 内容的责任对象会混淆。
- 责任：教材研发员与课程架构师；设计师补边界。
- 修正与复验：收窄为创作工具及其支持作者产出可访问内容的背景；最终界面按目标 WCAG/ARIA 与工程实测核对，或移除该映射。确认来源表不暗示设计文件自动适用 ATAG。

### UIUX-C05 — 无障碍缩放覆盖不足且缺少最小语义示例（P2，open）

- 位置：正文第 184—208 行；练习要求 200% 缩放。
- 发现：练习只指定 200% 缩放，没有 320 CSS px/400% 等价重排或横向双向滚动说明；若视为完成条件，会漏掉 WCAG 2.2 1.4.10 Reflow 的 AA 边界。正文又把具体 aria 属性和键盘行为完全交给工程，未给设计交接最小可观察语义例。
- 影响：视觉稿可看似完成，却无法判断动态结果、折叠状态、错误关联和高缩放下的可达性。
- 责任：教材研发员；设计师交语义规范；工程/QA 实测。
- 修正与复验：把 200% 标为早期版式练习，增加 320 CSS px/400% 等价重排、文字间距、焦点/动态通知验收，并给不绑定框架的最小语义示例。QA 按目标浏览器/辅助技术实测，静态文案不计通过。

### UIUX-C06 — 面试题型映射存在重复，主/次训练单元未声明（P2，open）

- 位置：sources-and-interview-map 第 31—39 行；course-architecture 第 8 节。
- 发现：能力簇表中 057—061 后又列 059、060；047—051 与作品集行 047—050 重叠，061、073、100—103 也跨行重复。跨能力训练合理，但没有 primary_unit/secondary_units 或重复仅作交叉训练的标记；课程架构又给每个 ID 指定主训练单元。
- 影响：按行计数会重复计算覆盖，无法合并两张表或确认哪些单元缺独立题型证据。
- 责任：课程架构师与竞品研究员；教材作者引用冻结映射。
- 修正与复验：为每个 ID 标主训练单元和可选次训练单元，删除同一行冗余 token，并附 001—103 展开计数。主映射唯一、交叉映射可解释，不能以总行数代替唯一 ID 数。

### UIUX-C07 — 面试研究 JSON 的声明哈希与收到文件漂移（P2，open）

- 位置：course-architecture 的 inputs；team/uiux-interview-questions-3m-research.json。
- 发现：课程架构登记 JSON SHA-256 为 7aa79f20...，工作区当前文件 SHA-256 为 0f2dfd9d...。当前 JSON 可解析，但架构仍写“第 73 行存在 JSON 语法错误”。当前题型证据无法按登记版本直接复现；这不是把当前文件判为无效，而是版本绑定失真。
- 影响：ID、来源性质和数量的机器核对可能针对不同版本。
- 责任：竞品研究员重新冻结；课程架构师更新 hash/状态；QA 核绑定。
- 修正与复验：决定唯一来源版本，登记新 hash、解析状态和变更记录，重跑 001—103 ID、来源数和主/次映射检查，旧报告保留版本差异。

### UIUX-C08 — 来源完整性与语义支持没有分层（P2，open）

- 位置：正文第 84—88、166—176、222—237 行。
- 发现：sourceHash/sourceVersion 和 exact source excerpt 同处结果模型，但没有区分哈希/版本只能证明身份，不能证明候选理由由摘录支持；excerpt 没有范围/核验状态，provenance.checkedAt 未进入 RetrievalState.result。
- 影响：学习者可能把可定位的版本化小节当成语义正确或回答已核实，来源失配与内容责任人的审校职责被压到同一字段。
- 责任：教材研发员定义契约；AI 生成/检索工程师交接字段；内容审校复核。
- 修正与复验：分出 identity/provenance 与 support/evidence 两层，补无摘录、摘录不支持、版本变化和责任人未核验状态；用歧义、来源冲突、版本更新夹具核对。

### UIUX-C09 — 视觉优先要求与当前教材证据不一致（P2，open）

- 位置：README 案例和层次/课程架构关系；author-handoff 视觉优先；正文第 110—141、157—188、202—208、408—440 行。
- 发现：当前只有 Markdown、ASCII 流程、表格和代码块，没有可直接审阅的 IA/状态/响应式静态视觉稿；作者交接也承认设计师后续需提供视觉稿。
- 影响：读者无法直接核对视觉优先标准、状态关系、焦点和窄屏重排，需自行补图。
- 责任：设计师提供视觉交接；教材研发员绑定图稿与图注；QA 渲染复核。
- 修正与复验：至少附主流程/状态图、结果卡状态板、窄屏/焦点关系图，标明教学假设、非运行截图和版本；概要版继续保留未完成声明。

### UIUX-C10 — 线性低/中/高保真序列需条件化（P3，advisory_open）

- 位置：正文第 160—164 行。
- 发现：文字易被初学者读成所有项目都必须逐级升级，没有说明探索性问题或资源约束下可在低保真与可运行原型间回退/跳过。
- 影响：学习者可能把保真度当固定阶段，过早投入视觉细节。
- 责任：教材研发员；课程架构师确认 09 与 13 单元迁移边界。
- 修正与复验：标为一种路径，补回退或跳过中保真的反例和选择依据；扩写单元时复核。
