# v13 c01 选型章节内容审校

审校岗位：内容审校员  
审校对象：`textbooks/v13/c01-selection.md`  
审校范围：核心机制、四方案、失败边界、公平比较、练习、图文一致性与来源/验证状态。  
结论：`reviewed_with_limitations`

## 已保留且表达清楚的内容

- 保留“下一步由谁决定”这一核心机制，清楚区分普通程序、单次模型、固定 workflow 与动态 Agent。
- 四种方案均有同一缺陷分析任务下的实现方式、升级条件和放弃条件，且明确动态程度不代表质量更高。
- 保留材料完整、关联文件路径变化、同级规则冲突三类输入情形；`WAIT_INPUT`、只读调查、权限/预算/恢复护栏等停止边界没有被删除。
- 多 Agent 章节仍要求证据子问题可独立核对、修订和权限一致，并保留单一写入者与版本冲突拒绝合并规则。
- 公平比较部分覆盖共同任务集、权限和工具版本、验收器、资源上限、正确等待/错误完成、用量、延迟、未知结果和失败类型，未虚构性能排名。
- 练习包含固定字段、未知路径、版本冲突和升级实验，参考解法与正文选型原则一致；一页复盘卡能把判断落到任务合同和停止条件。

## 需要保留的限制与问题

1. **章节内链接在 v13 目录中无法独立解析（P1 内容交付问题）**：文件引用 `f02.md`、`02-task-acceptance.md`、`e02.md`、`c01-control-primer.md`，但 v13 当前目录只有本章和视觉笔记。若 v13 交付按逐文件阅读，先修、评价章节和下一章均会断链；合订本组装时必须将这些链接重写为实际 v13 路径，或补齐 v13 目标文件并复核链接。
2. **候选视觉稿的状态表达是诚实的，但需防止接入时被误读**：正文已标注“静态设计候选稿、未验证浏览器/窄屏/无障碍/真人理解”，没有把图示写成实测结果。接入教材或产品时应继续保留状态徽章和文字替代；当前审校不把候选稿视为已验证教学效果。
3. **Mermaid 判断图与四方案表不是逐节点一一映射**：图中“材料足够且规则稳定”汇到“普通程序或单次模型”，但没有显示模型只写候选、代码构造输入的约束。正文后续说明已补足机制，仍建议图下保留一句“单次模型不获得下一步控制权”，避免读者仅看图时过度概括。
4. **“材料已经足够”与“规则能稳定决定路径”是教学简化轴**：正文已通过情形 B、C 和动态只读限制补足边界；但真实项目还需产品定义“足够”和“合理覆盖”的验收口径。本章没有自创阈值，保留为后续产品/测试交接项。

## 来源与验证检查

- 本章新增内容主要是内部教学构造、统一缺陷任务和练习，没有发现无来源的外部性能、排名或能力断言。
- 章节明确声明比较为推理演算，图为候选稿，未把静态图、伪代码或练习当成运行证据。
- 本次审校未执行浏览器渲染、模型调用、外部契约或真人理解实验；这些状态不能由本报告替代。
