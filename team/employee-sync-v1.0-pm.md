## 全员共同口径

1. 1.0 是本地候选学习工作台，不是公网生产服务，不授予职业认证、就业、真人专家认可、真实学习效果或行业先进性结论。
2. 当前任务 → 阅读/检索 → 练习 → 作品提交 → 反馈状态 → 复盘是主流程；阅读、题库、自评和本人自述都不能直接变成能力结论。
3. 当前与历史教材、账户记录、题集、索引和旧 QA 保留各自身份；新版本只追加证据，不覆盖失败、旧来源或正式数据库。
4. 本地规则/BGE检索、服务端API和未来真实模型调用分开标记；没有依据时用澄清、未覆盖、不可用或证据不足，不编造教材答案。

## 本轮开发顺序

1. 客户端：四态当前任务与P01本地版本化提交已实现，保留localStorage边界和历史提交链。
2. 后端：P01提交接口与修订链已实现，下一步透传学习查询的检索元数据和相关未覆盖状态。
3. 检索：正文、索引、向量和来源哈希已核对，直接recommend/dialog元数据已补；学习查询路由仍需后端映射。
4. 测试：以上三项完成后重新冻结当前源，使用隔离临时账户/端口执行V1-01..09；浏览器、HTTP、P01恢复和无障碍证据不得用静态断言替代。
5. PM：根据新QA逐项记录通过、不足、失败、原因、责任、修复和复验，保留整体`not_met`。
