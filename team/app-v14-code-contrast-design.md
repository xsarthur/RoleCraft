设计师；2026-10-12（Asia/Shanghai）。输入为用户代码区浅底浅字反馈、PM 对截图症状描述、当前 AGENTS 有效授权，以及只读 `dist/styles.css`、`learning-workbench.css`、`learning-experience-v13.css`。本稿只交配色，不改应用代码、教材或产品门槛；实际截图原像素与浏览器 computed style 由独立 QA 核，不以源码推断全部渲染效果。

## 原因与统一主题

收到 CSS 中，workbench 给 `.lw-code` 深底 `#182b23`，代码正文 `#e7eee7`、语言标签 `#bbccbd`；experience 后续只将容器底色改成 `#f3f0ea`，保留浅字。纯色计算当前代码字/米底约 **1.04:1**、语言字/米底约 **1.48:1**，能解释用户反馈的低对比症状。这里只归因已读规则组合，不认定实际浏览器加载顺序和像素已经验证。

沿当前暖米色阅读主题统一为**浅米底、深色字**。代码正文使用已有页面深墨色，语言标签使用已有深辅助色。颜色要作为同一组落实到围栏容器、pre、pre内code及语言说明，不能再次只覆盖背景；无需为本次修复引入语法高亮。若有嵌套文本节点/已有token着色，也应继承这组深色或使用独立核对后的深色，不留浅绿残项。

| 部位 | 字色 | 背景 | 计算对比 / 交接 |
| --- | --- | --- | --- |
| 围栏代码正文 `pre` 与其中 `code` | `#3d3929` | 容器 `#f3f0ea`；pre透明继承 | **10.17:1**；正文不能继续继承旧浅字 |
| 代码语言说明/顶部标签 | `#6b6356` | `#f3f0ea` | **5.21:1**；文字独立显式取色 |
| 代码块边界、标签分隔线 | 无 | `#dcd7cc` | 与现有卡片协调；分隔不是表达代码含义的唯一方式 |
| 正文行内 `code` | `#3d3929` | `#ece7dd` | **9.39:1**；完整字串不因弱化样式变不可读 |
| 围栏/行内代码选中文本 | `#ffffff` | `#755624` | **6.75:1**；同一选区明确前景与背景，不只改一方 |
| 必要聚焦边界 | `#755624` | 周围 `#f3f0ea` 或白底 | 约 **5.93:1 / 6.75:1**；沿现有3px可见框，保持边界可辨 |

上列数值是本设计色值的相对亮度计算结果，使用sRGB线性化与 `(较亮亮度+0.05)/(较暗亮度+0.05)`，不是浏览器截图测量，也不是自行添加的产品通过阈值。数值保留两位；透明叠层、opacity、文字抗锯齿及系统选区均须看实际呈现。官方对比资料读取本次未返回，不据此声称完成 WCAG 合规审查。

## 局部落实与检查交接

前端唯一 owner 在当前 experience 主题层补齐相关显式颜色，优先限于教材阅读的 `.lw-code`、其语言说明、`pre/code`、正文行内code和相应选区。不改变全局历史工具主题；避免无区别全局 `code` 改色造成旧深底代码区黑字。pre内code仍透明、无行内胶囊底，不让行内code规则盖住块级代码。语言条使用温和浅分隔线，不保留旧深绿分隔造成错误深色主题印象。

代码块若已可键盘聚焦/水平滚读，沿既有交互保留；聚焦框须在 overflow 裁切情况下仍可见，可用内侧框/等价处理，不能依赖在容器外被裁掉的轮廓。本次不新增复制按钮、执行按钮、语法解释、代码内容或滚动行为。保持原字号、间距、等宽字体、水平滚动、行内换行策略及手机布局；不以颜色修复扩大到整页改版。

QA 对最终独立新绑定查看实际加载 CSS/计算前景背景，覆盖长围栏、语言标签、行内code、选中及现有可聚焦滚动代码区，并核窄屏仍可阅读、正文和下载内容未变。用户截图对应例须按实际篇节复验，另检查一个有语言说明的围栏及一个行内代码，防止只修单个块。前端自检和本设计计算不代替 QA；已冻结 v14 对话/详情及教材历史报告保持。

领域自查：根因给出收到规则依据；配色与现暖米主题一致；前景/背景/标签/选区/焦点成组交接；修改范围仅视觉颜色，未改教材、数据、交互或验收。当前交付是设计方案，用户认可和完整培养/行业目标不因修复方案产生。
