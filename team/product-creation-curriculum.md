# 从 0 到 1 的 Agent 产品创造教学路线

教学草案 v0.1，2026-10-10；正式正文与专业评审待完成。目标是在岗位能力之外，培养发现行业机会、实现产品、验证价值并持续改进的能力。原 12 模块保留，本路线以真实产物串联它们。

## 七阶段与产物

1. **行业问题与用户证据**：学习区分用户原话、观察行为与作者假设。提交目标群体、真实任务、访谈或观察记录、现有替代及反例；复盘是否找对用户，问题有没有独立证据。
2. **现有产品与研究基线**：学习选择代表性产品、人工或简单流程替代，建立相同任务、版本和资源条件的比较。提交来源及访问日期、基线结果与比较局限；复盘有无遗漏替代、宣传是否误作实测。
3. **差异化与验证假设**：将价值差异写成可证伪假设，先定主要指标、护栏及停止条件。提交假设与实验计划；复盘用户为何改变行为，什么证据会推翻假设。未知阈值待确认，不能造数。
4. **设计与 MVP 实现**：学习实现足以检验假设的端到端任务、异常路径及可复现版本。提交交互说明、代码、环境与演示；复盘模拟数据、人工干预和实际能力的边界。
5. **性能安全成本与质量评估**：学习可比评估、保留案例、重复试验、故障恢复和护栏验证。提交基线对比、轨迹、质量和成本报告；复盘是否挑最好结果、评分器是否有误，改进是否造成回归。
6. **真实使用验证与交付**：观察目标用户实际任务、采用障碍和价值效果。提交行为证据、反馈、负面结果与交付说明；复盘谁受益、谁退出及结果能推广的范围。小样本试用不能自动提供因果证明。
7. **持续迭代**：将问题转成行动、责任人、版本与复验。提交改进、回归、新任务及遗留记录；复盘改进是否奏效、未达标问题是否仍开放。

## 教学评价与每次复盘

各阶段先约定产物标准，再判断达标、未达标或证据不足。严谨证伪可以证明学习能力，但被反驳的产品假设仍失败。教材完成、招聘对标、自述或 Demo 可运行不证明行业先进。先进性需明确行业任务和日期，在可比条件下与代表性现有方案比较，兼顾用户价值及技术护栏，并有真实使用、独立专业审查和可复现证据。

每次产出填写目标、版本、证据、结论、差距、原因、改进、责任人、复验方法与结果；未复验不得关闭。证据不足先补测量，负面结果应如实保留，不能只写心得。

## 方法依据与范围

[NSF I-Corps FAQ](https://www.nsf.gov/funding/information/faq-i-corpstm-team-solicitation) 支持问题、利益相关者、价值假设及客户发现；这是历史项目方法，不继承其招生或访谈数量规定。[Microsoft Research](https://www.microsoft.com/en-us/research/articles/patterns-of-trustworthy-experimentation-pre-experiment-stage/) 支持可证伪假设、成功与护栏指标、可信实验设计。[Anthropic Agent 评估](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) 支持真实结果、轨迹、重复试验及线上线下证据互补。三页均访问于 2026-10-10。

七阶段及评价门槛是课程架构师的教学推导；这些方法来源不证明当前产品领先。领域自查：七阶段字段齐全、原 12 模块均关联、来源已访问；正文、专业评审与真实效果仍待完成，独立复核交给相应岗位。
